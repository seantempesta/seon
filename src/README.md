# src/
Seon's own code: `seon.*` (the platform: the fork server, writer, agents, reconciler, tasks, store, printer, renders, the server and the dashboard) and `my.*` (the functions an agent calls at its REPL). Each namespace's docstring says what it owns; the wiki's map, `docs/README.md`, says how the pieces fit. A merge writes this tree back from main's program (`docs/source.md`).
