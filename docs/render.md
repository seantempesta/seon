# Rendering, Living Canvas, 3-Level Progressive UI, and Single-Source Context

Seon renders HTML for humans and structured context for LLMs from ONE reactive walk (`seon.render`, `seon.render.*`, `seon.model.wire`), guaranteeing that what appears in the browser matches what agents receive on the wire.

## 1. Incremental `datahike.reads` Walk & Reagent Event Wiring (`seon.render`, `seon.store`)

`seon.render/step-walk` and `seon.render.walk` track per-tile `datahike.reads/reads-index` read-sets across Canvas, Workspace (`ws-*` + `#tile-*`), and Debug (`10` independent `#dbg-*` units) so untouched panels do zero work on commits or high-frequency streams (`0.02 ms/frame` incremental, `:debug` warm full `229.09 ms -> 8.60 ms` measured `[M]`, >400x headroom inside an `8.33 ms` 120 fps frame budget).

- **Datom-native rule projection (`seon.rule`, `seon.rule.context`, `seon.rule.seed`, `resources/seon/rules.edn`):** 58 editable `:seon.rule/*` Datahike entities derive visibility, data-driven function discovery (`:rule.expand/schema-contract-fn`, `:rule.expand/direct-callee-fn`, `:rule.expand/doc-by-ref` — zero hand-crafted tool tags), test gating (`:rule.gate/*`), error surfacing (`:rule.error/*`), print policy (`:rule.preview/*`), KV-cache zone (`:static-prefix` vs `:ephemeral-tail`), layout mode, parameterized view flags (`:view.param/*`), modifier tags (`:view/tag`), and cycle-safe Graph->Tree nesting (`:view/parent`) for **both** `:target :html` and `:target :wire`.
- **Unified 4-stage recursive rule-driven printer (`seon.render.print.*`, `seon.render/render-value`, `seon.model.wire/format-eval-output`):** Fingerprints root and nested sub-schemas via `seon.schema.index`, derives O(1) print policy from `:rule.preview/*` rules, builds ONE breadth-before-depth token-budgeted Selection Tree with explicit `:elision` nodes & cycle guards, and emits BOTH Hiccup (delegating nested `:seon.render/hiccup` renderers inline) and crisp Markdown with exact `(user/expand! ...)` continuations (`10k` vector in `2.43 ms` `[M]`).
- **Cache-transparent read tracking (`seon.store/lru-get!`):** Datahike index cache hits capture and replay read ranges into `datahike.index.interface/*reads*`, guaranteeing cached reads stay 100% reactive across live SSE ticks, incremental `seon.rule/step-rules`, and page reloads.
- **Auto-injected stable IDs & fault isolation:** `render/ensure-root-id` injects deterministic `:id` attributes for clean Datastar Idiomorph morphing, and every component/action executes inside an isolated fault card boundary.
- **Standard Reagent events:** `:on-click`, `:on-submit`, and `:on-change` accept `#(...)`, `[fn args]`, bare `fn`/`var`, or quoted `'(ns/fn args)`. `POST /call` validates `^:seon/callable` (`seon.web.actions`), dispatches asynchronously onto `ui-ch`, and coalesces targeted SSE DOM morphs at `8 ms` (`120 Hz`) over `/events`.
- **Clojure-data CSS (`seon.web.styles`, `seon.web.css`):** UI styles compile cleanly from Clojure data structures without duplicating raw CSS blobs.
- **Schema-attached parameterized tiles (`seon.render.tiles`, `seon.render.ns-tile`, `seon.error`):** Malli schemas declare `{:seon.render/hiccup ns/fn}` pointing directly to real tile renderers (`seon.render.tiles/*`, `seon.render.ns-tile/ns-tile`, `seon.render.lineage/task-lineage-tile`, `seon.error/render`).
## 2. Inside-Out User Viewport, Living Canvas & Chronicle (`seon.render.canvas`, `seon.render.chronicle`)

User navigation state (`:seon.user/viewing`, `:seon.user/view-mode`, `:seon.user/sidebar-open?`, `:seon.user/expanded-agents`, `:seon.user/as-of-tx`) lives exclusively on `:user/default` in Datahike. Any agent can move the user's browser live via `(user/show-user! ...)`.

- **Collapsible Recursive Left Sidebar (`#seon-sidebar`):** Walks `:seon.agent/parent` refs recursively with live streaming status indicators and 1-click expand/collapse.
- **`:canvas` (Agent-Perspective Composable Living Canvas, `seon.render.canvas`, `seon.render.canvas.live`, `seon.render.chronicle`):**
  - **Uniform Agent Perspective (Zero `:agent/root` Special-Casing):** Viewing ANY agent shows (1) **Parent Request** (`parent-request-section`: clickable `↑ parent`, assigned `:seon.task/*`, incoming `:seon.agent.call/*`), (2) **Live Self Work** (`self-work-section` + `render-in-flight-panel`: instant user ack, pulsing status, own universal merge-gate pills `[tests ✓/✗ · ready/merged]`, 1-click live thinking toggle, and live expandable `Thinking & actions` showing latest `:intent` collapsed and full Thinking / Intent / Code / Output / Result expanded — mounted even above custom `:seon.agent/render-fn`!), (3) **Children & Subagents Progress** (`render-work-progress`: recursive tree of outgoing calls + child agents with live intents and merge-gate readiness — clicking any child jumps straight into its Canvas), and (4) **System Pulse** (`#cv-bench-runs` live benchmarks + Chronicle Living Hero `#cv-living-hero`).
  - **Composable Render Functions & History:** Agents evolve their UI without discarding prior work via `(seon.render.canvas.live/compose-live-canvas ctx {:visual ...})` + `(user/set-render! 'ns/fn)` (or `(user/canvas! ...)`). Every `(user/canvas!)`, `(user/set-render!)`, or render-fn edit advances top-bar **`◀ N / M ▶ · Live`** Datahike `d/as-of` history.
  - **Single Source of Truth for Humans & Agents:** The exact same `parent-request-section` and `render-work-progress` Hiccup functions drive both the Browser Canvas and coordinating agents' `<neighborhood-activity>` via `render/hiccup->text`, plus `(user/monitor)`.
- **`:workspace` (Chronological Chat + Live Context Tiles):** Calm chronological timeline on the left, live auto-discovered `@seon.ctx/ctx` and `result/e<n>` tiles on the right (`seon.render.workspace` / `seon.render.ui`).
- **`:debug` (Zero-Cost Wire & System X-Ray, `seon.render.debug`):** Exact LLM wire request, live `@seon.ctx/ctx` pull snapshot, side-by-side Human HTML vs Model Text (`render/hiccup->text`), per-unit `datahike.reads` sets, test verdicts, and 3-way branch diffs.
## 3. Single-Source Wire Format, XML Session Framing & Ephemeral Tail (`seon.render.wire`, `seon.render.tail`, `seon.model.wire`)

Wire assembly (`seon.render.wire/build-live-wire-request`) runs `seon.rule.context/derive-context` (`:target :wire`) with branch-first `:task-db` resolution and `walk-prefix-cache` anchored to `merge-base` + `:seon.rule/id` signature (`86–96%` KV cache hit rates measured `[M]`):

1. **Byte-identical `system` prompt** (KV prefix anchor).
2. **Example sessions (`:seon.agent/examples`):** Framed in `<session id="example/..." kind="example" from="seon">` using the exact same `user`/`assistant`/`tool` wire roles.
3. **Live session opening:** `<agent ...>` + static `<walk-context>` (`:static-prefix` rule-projected tiles — `ctx-tile`, `task-tile`, `task-lineage-tile`, promoted `ns-tile`/`var-tile`/`schema-tile` — rendered via `render/render-tile-node` + `render/hiccup->text`).
4. **Append-only conversation turns:** Exact `user`, `assistant` (`content` + `reasoning_content` + `tool_calls`), and `tool` (`result/e<n>`) messages.
5. **Ephemeral tail (`seon.render.tail` + `<rule-tail>`):** Volatile `:ephemeral-tail` rule tiles (`<rule-tail>`), `branch-status` (with turn budget), `system-health`, `neighborhood-activity`, `chronicle-tail`, and — when a human tab is viewing — one ephemeral `live-viewport` screenshot (`target/seon-browser`), replaced every turn and never persisted in history.
6. **Debug Provenance (`seon.render.debug`):** Debug View displays `#dbg-rule-trace` (active rules, fired count, WM facts, ms, per-rule read/assertion table) plus side-by-side true `:mode :human` HTML (with `Why:` provenance & modifier tags) vs exact `:mode :agent` Model Text.

## 4. Distributed Schema Rendering, Eval Breadcrumbs, Live Queries & Boards (`seon.render.breadcrumbs`, `seon.query`, `seon.board`)

- **Universal Cross-Agent Schema Dispatch (`:rule.view/default-by-schema-render`, `:rule.view/default-by-main-schema-render`, `:rule.view/fallback-schema-printer`):** Any entity whose Malli schema registers `:seon.render/hiccup` (auto-extracted to `:seon.schema/render` in `seon.schema/validate-schema-registration!`) renders automatically on EVERY agent — even unrelated specialists on older branches — with zero custom rules or bespoke `:seon.agent/render-fn`. Schemas without a custom renderer automatically fall back to `seon.render/render-entity-value` (4-stage zero-clipping schema self-printer).
- **Eval-Triggered Rendering & Live Breadcrumbs (`seon.render.breadcrumbs`, `seon.model.wire/format-eval-output`):** Passing the immutable `walk-db` (with branch `fallback-db` only for newly registered schemas) into `format-eval-output` runs `:render-root? true` schema dispatch on maps and lookup refs while preserving >90% KV-cache stability, and appends live breadcrumbs (`:seon.code.var/schema-refs` consuming functions, `:seon.code.doc/references` citing docs, outgoing/incoming schema refs, and `d/pull` drill-in forms). `:rule.expand/eval-schema-fn`, `:rule.expand/eval-schema-doc`, and `:rule.layout/show-schema-breadcrumbs` surface the same breadcrumbs interactively in HTML and Model Wire.
- **Reusable Domain-Neutral Live Primitives:**
  - `seon.query` (`:seon.query/entity`): Read-only executable Datahike queries (`:datalog`, `:index-slice`, `:rule-trace`, `:schema-fingerprint`, `:health`, `:walk-reads`, `:entity-pull`) measured inside `datahike.reads/with-reads` (forwarding reads to outer `di/*reads*` so embedded live queries auto-update via SSE).
  - `seon.board` (`:seon.board/entity`): General multi-section interactive live data boards projected to `:view/zone :canvas` (`:rule.view/canvas-surface-for-board`) and rendered by standard `seon.render.canvas/default-canvas`, with Human UI / Split Parity / Model Wire toggling and an interactive Entity Inspector (`:seon.board/inspect`).
- **Lazy Hiccup Reactivity (`seon.render/step-walk`):** `step-walk` executes both `comp-fn` and `hiccup->html-with-handlers` inside `datahike.reads/with-reads`, guaranteeing lazy `(for ...)` sequences and nested component expansions capture exact datom read dependencies for instant Datastar SSE morphs. `seon.render.ui/page-unit-specs` dereferences `#'seon.web.styles/full-css` via `var-get` so live CSS edits hot-patch running daemons immediately.
