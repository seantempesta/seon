# Rendering: ONE Rule-Projected Surface, Upgrade Ladder & Single-Source Wire

Seon decouples data from rendering into **one reactive pipeline** (`seon.ctx/project-entity`, `seon.render.surface`, `seon.render.fit`, `seon.render.entities`, `seon.render.entities.work`, `seon.render.entities.infra`, `seon.signals`, `seon.render.wire`) — driving both real-estate-adaptive 120 fps browser HTML (`:target :html`) and KV-cache-safe OpenAI Wire context (`:target :wire`) from the exact same Datahike ref graph and pure Hiccup functions.
## 1. Programmatic Ref Graph & Mechanical Renderer Discovery (`seon.render.fit`, `seon.render.entities`)

All relationships live as standard Malli/Clojure/Jolt/Datahike `:db.type/ref` edges:
- **Schemas (`:seon.schema/*`):** `:seon.schema/keys`, `:seon.schema/optional-keys`, `:seon.schema/ref-targets`.
- **Vars (`:seon.code.var/*`):** `:seon.code.var/input`, `:seon.code.var/optional-input`, `:seon.code.var/output`, `:seon.code.var/calls`, plus `:seon.code.ns/requires-ns`, `:seon.test/var-ref`, and `:seon.code.doc/references`.
- **Renderers are ordinary pure `ns-map -> ns-map` functions:** Any pure var (empty `:seon.code.var/ops`, non-private, non-test, non-`^:seon.flow/edge`) whose `:seon.code.var/output` includes `:seon.ui/hiccup` is discovered mechanically via `seon.render.fit/discover-renderers` (indexed `:avet` intersection of `:seon.code.var/input` and `:seon.code.var/output`).
- **Multi-level complete thoughts (`seon.render.entities`, `seon.render.entities.work`, `seon.render.entities.infra`):** Core entities (`var`, `form`, `message`, `error` + nested `fix`, `task`, `schema`, `doc`, `test`, `eval`, `ns`, `agent`, `call`, `rule`, `system`) each have pure renderers (`chip`/`badge`/`row` -> `sig`/`card` -> `full`) tagged with integer `:data-min-width` / `:seon.ui/min-width` hints, alongside rich work/summary renderers in `seon.render.entities.work` (`seon.render.entities.work/render-ns-full`, `seon.render.entities.work/render-task-lineage`, `seon.render.entities.work/render-bench-run-card`, `seon.render.entities.work/render-health-report`, `seon.render.entities.work/render-summary-card`, `seon.render.entities.work/render-ctx-snapshot`), `seon.render.entities.infra` (`seon.render.entities.infra/render-form-card`, `seon.render.entities.infra/render-message-card`), `seon.render.status/render-status-card`, and `seon.error/render`.
## 2. 3-Signal Native Rank & Dual-Target Complete-Thought Upgrade Ladder (`seon.render.fit`, `seon.ctx.project`)

Candidates from `seon.ctx/gather-agent-candidates` and generic 2-read world discovery (`seon.ctx.project/agent-world-datoms`) pass through one pure rank-and-fit pipeline:

1. **3-Signal Native Datahike Rank (`seon.render.fit/rank-candidates`):** Scores each candidate with zero synthetic `age` machinery using tunable weights (`:seon.config/rank-weights`, read by `seon.render.fit/read-rank-weights`):
   - **Urgency / Anchor:** Open `:seon.error/status`, matching `:seon.fix/*`, failing reach tests, branch-edited vars, active `:seon.agent/tasks`, and pinned refs.
   - **Recency:** Native Datahike `max ?tx` / `:seon.agent.eval/turn` normalized across the candidate pool (re-touching an older entity snaps it straight back to the top).
   - **Derived Touches / Convergence (`seon.ctx.touches/derived-agent-touches`):** Uncapped live in-memory `datahike.reads` + raw `d/changes` branch writes + eval mentions (zero persisted `:seon.agent.eval/touched` / `:touched-refs` LMDB writes) plus converging rule/ref paths hitting the entity.
2. **2-Pass Complete-Thought Upgrade Ladder (`seon.render.fit/upgrade-ladder`, `seon.render.fit/fit-projections`):** Pulls each ranked entity once, runs its eligible pure `:seon.ui/hiccup` renderers, and measures actual `:tokens`, `:chars`, `:min-width`, `:area`, and `:lines` via `seon.render.fit/measure-hiccup` — upgraded automatically with real browser-measured `(w, h, overflow-x?)` boxes cached in memory via `seon.render.fit/record-browser-box!` / `seon.render.fit/cached-browser-box` (0 LMDB writes). Pass 1 picks the smallest complete thought for top-ranked items; Pass 2 upgrades in rank order (`:breadth-first` or `:depth-first`) while respecting both total budget and optional `:per-item-budget` caps — never clipping mid-thought. Inspect every variation and fit decision via `seon.render.fit/explain-candidates` and `seon.render.fit/explain-entity-fit`:
   - **`:target :html` (Responsive Real-Estate Fit):** Browser viewport `:seon.user/viewport-w` x `:seon.user/viewport-h` syncs debounced onto `:user/default` via `seon.web/set-viewport!`. `seon.render.fit/resolve-slot-budget` computes container slot geometry (`:seon.ui/slot`, `:seon.ui/avail-w`, `:area-budget`, `:max-items`), skipping browser-overflowing variations and picking rich cards/panels on wide desktop (`1440x900`) and compact chips/bars in sidebars or narrow mobile (`430x900`) — zero arbitrary `@media` layout cutoffs.
   - **`:target :wire` (KV-Cache Token-Budget Fit):** Fits `:seon.view/token-budget`, `:per-item-budget`, and `:seon.view/max-items` using the `already-shown` self-emptying queue (`seon.ctx.project/compute-shown-delta`): unchanged items cost `0` repeated tokens, re-touched `?tx` deltas re-warm cleanly, upgrades append only new detail, and output orders least-volatile -> most-volatile for KV-cache prefix stability.
## 3. Five Ambient Operational Signals (`seon.signals`)

`seon.signals/all-signals` derives 5 ambient signals via indexed Datahike reads in `< 5 ms` (cached per commit-id via `seon.store/lru-get!` with `datahike.reads` replay):
- **Flow (`:seon.signal/flow`, `seon.signals/read-flow-signal`):** Running, waiting, stalled, blocked, and ready agent counts + live pulse state.
- **Pressure (`:seon.signal/pressure`, `seon.signals/read-pressure-signal`):** Eval tick/byte allocation percentages against `:seon.config/eval-ticks` / `:seon.config/eval-bytes` and UI frame-ms pressure.
- **Context (`:seon.signal/context`, `seon.signals/read-context-signal`):** KV-cache prefix reuse %, token budget utilization, eval success %, and prefix busts.
- **Proof (`:seon.signal/proof`, `seon.signals/read-proof-signal`):** Cached green / failing / unproved tests and branch merge readiness.
- **Health (`:seon.signal/health`, `seon.signals/read-health-signal`):** Structural errors, open errors, warnings, and oversized namespaces.

Rendered ambiently as status dots, hairline heat bars, and subtle `:calm` / `:warm` / `:hot` shading/pulse via `seon.signals/render-signals-bar` (`>= 220px`) and `seon.signals/render-signals-panel` (`>= 560px`), auto-selected by the Upgrade Ladder (no car metaphors).

## 4. ONE Surface Walker, 120 fps Shell & Generic `d/as-of` Time-Travel (`seon.render.surface`, `seon.render`, `seon.render.ui`)

- **ONE Surface Walker (`seon.render.surface/render-surface`, `seon.render.surface/build-surface-model`):** Powers `:session`, `:context` (Context Lab / Explain), `:system`, and `:inspect` (Entity Full View) — alongside legacy `:canvas`, `:workspace`, and `:debug` aliases — inside `#seon-view-unit` via `seon.render.surface.session`, `seon.render.surface.context-lab`, `seon.render.surface.inspector`, `seon.render.surface.entity`, and `seon.web.router`. Live Canvas updates automatically from active agent work (`seon.render.surface.session/canvas-live-progress`: thinking, spawned/forked subagents, streaming call results, diffs) while still supporting direct focal overrides; `:context` / `:debug` inspects exact OpenAI Wire messages, Upgrade Ladder traces, `seon.rule` firing traces, and side-by-side Human HTML vs `seon.render/hiccup->text` Model Text.
- **Generic Entity-Derived Time-Travel (`seon.render.data/view-history-txs`, `seon.render.surface/render-surface-timeline`):** Computes sorted distinct Datahike transaction IDs across all projected entities, agent-linked refs (tasks, pins, curated, errors), user messages, and replies — powering `<-` / `->` `d/as-of` scrubbing uniformly across views without static summary lists.
- **Inside-Out Viewport & Incremental `datahike.reads` Walk (`seon.render/step-walk`, `seon.render.walk`, `seon.render.ui/page-unit-specs`):** Navigation state (`:seon.user/viewing`, `:seon.user/view-mode`, `:seon.user/sidebar-open?`, `:seon.user/expanded-agents`, `:seon.user/as-of-tx`, `:seon.user/viewport-w`, `:seon.user/viewport-h`) lives exclusively on `:user/default` (live-movable via `(user/show-user! ...)`). `seon.render/step-walk` tracks per-unit `datahike.reads` (including lazy sequences and `seon.store/lru-get!` read-replay) across 6 mounted units (`#seon-css` from `seon.web.styles/full-css`, `#seon-header`, `#seon-sidebar`, `#seon-view-unit`, `#seon-stream-unit`, `#seon-composer-unit`) with `seon.render/ensure-root-id`, `^:seon/callable` Reagent events (`seon.web.actions`), `120 Hz` (`8 ms`) coalesced Datastar SSE morphs, Chronicle milestones (`seon.render.chronicle`), and live benchmark cards (`seon.render.entities.work/render-bench-run-card`).

## 5. Single-Source OpenAI Wire & Eval Output (`seon.render.wire`, `seon.model.wire`, `seon.render.print`)

`seon.render.wire/build-live-wire-request`, `seon.model.messages/build-agent-wire-messages`, and `seon.model.wire/format-eval-output` share the exact same Hiccup -> `seon.render/hiccup->text` pipeline (`86–96%` KV-cache hit rates `[M]`):
1. **Byte-identical `system` prompt & graph-driven agent prefixes (`seon.model.messages/render-prefix-agents`):** KV prefix anchor followed by parent fork sessions (`:seon.agent/forked-from`) and curated example sessions (`:seon.agent/example-refs` / `:seon.agent/examples`) assembled mechanically from Datahike graph edges with zero `:seon.agent/role` or `:seon.agent/prefix-mode` enums.
2. **Merge-base-anchored `<walk-context>`:** Derived via `seon.ctx/project-entity` -> `seon.render.fit/fit-projections` (`:target :wire`, strict zero-repetition `already-shown` queue, least-volatile -> most-volatile ordering) -> `seon.render/hiccup->text`.
3. **Append-only conversation turns (`user` / `assistant` / `tool`):** Every eval result runs `seon.model.wire/format-eval-output`, emitting **100% valid Clojure EDN maps** (`{:seon.eval/turn ... :seon.eval/handle result/e<n> :seon.eval/ok? ... :seon.eval/value ...}` — zero fake `; ` comments), preferring discovered `:seon.ui/hiccup` renderers (`seon.render.fit/discover-renderers`) and falling back to the 4-stage breadth-before-depth schema printer (`seon.render/render-value`, `seon.render.print`) -> `seon.render/hiccup->text`, with exact `(user/expand! ...)` drill-ins and live schema breadcrumbs.
4. **Live `<context-delta>` & optional `<live-viewport>` (`seon.render.wire/build-live-wire-request`):** Emits ONLY entities that are new, changed (`?tx`/hash bump -> `:rewarmed`), or explicitly requested with a new renderer `:fn` not yet shown at that `?tx` (never repeating unchanged entities), plus optional live `WKWebView` frames.
