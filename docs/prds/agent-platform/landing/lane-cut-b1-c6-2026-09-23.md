## The decision the conversion needs (B4, not B1)

"The commit id is the publication" answers the seal digest. It does not answer
the two facts the seal carries today:

1. The program-digest basis. `derive-program-digest` hashes the rows written
   since the seal's transaction. Without a seal, the basis has to be the
   transaction of the published commit the branch forked from.
2. The external-input identity (`:seon.source/test-input-digest`). This is the
   evidence for test admission and currency. The README §4 B4 §2a ruling
   (60ac32505) makes test evidence content-keyed. Under that ruling the digest
   is computed at request time from `seon.test.cache` input digests. It is not
   read from a stored row.

Both changes belong to the test-overhead lane's B4 steps. The seal and
`publication-input-digest!` are deleted in the same commit as those steps,
together with the cluster.clj readers. The owner of that commit must hold
`test.clj`, `runner.clj`, `cluster.clj`, `source.clj`, `seon.source.edn`,
`artifact.clj`, `web.clj` and the fixture files.
