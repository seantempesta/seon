### N4 (`310d4235d`)

- `boot/start!` forces a `defonce` delay that calls `Thread/setDefaultUncaughtExceptionHandler` once
  per JVM. The handler delegates to the handler it replaced. It calls `record-uncaught!` through the
  Var, so a reload changes behaviour without installing it again.
- Attribution uses only carried evidence: the first `:seon.env/environment` in the throwable's
  `ex-data` chain. If there is none, it uses the sole live instance's environment, and root receives
  the fault. The failure is recorded through `cluster/commit-fault!`, today's recorder.
- If several instances are live and nothing is carried, or if the database refuses the recording,
  both modes panic: `prn` to stderr with `Throwable->map` of the cause and of the outcome. Under
  `:panic` a stored fault is also printed loudly.
- Not included:
  - removing the handler (it is installed for the JVM's lifetime);
  - a receipt row, because M4's receipts do not exist yet;
  - http-kit `:error-logger` (owned by web.clj).
- Before the change, default had no default handler (`Thread/getDefaultUncaughtExceptionHandler` → nil,
  probe on pid 65889, 0.5 ms).

  symlinked):

## Slice 1: stop is a join. NOT LANDED (held uncommitted; patch `tmp/m4-flow/slice1-executor-join.patch`)

Implemented per the idiomatic-join note, with no fork:

- `seon.flow/start-graph!` gives each graph its own `newThreadPerTaskExecutor` of virtual threads,
  with the projection bound in the thread factory. It returns this as `::executor`.
- New `seon.flow/join-graph!` calls `.shutdown`, then awaits `.awaitTermination` through
  `seon.await/await!`, using an `IBlockingDeref` adapter.
- `:seon.await/deadline-nanos` (optional, in `:seon.await/bound`) carries one deadline.
- `disarm!` and `disarm-agents!` use one deadline for the armer quiescence (converted to `await!`
  port operations), every agent graph, the cluster graph and the fault graph.
- `arm!` refuses with `:seon.agent/graph-exited` while the previous graph's executor is shut down but
  not terminated. Once it has terminated, `arm!` finishes the teardown and arms a fresh graph.

  member.
- `await-turn-completion!`.
- The armer's stop `put!`.
- The launcher's `proc-stopped`.
