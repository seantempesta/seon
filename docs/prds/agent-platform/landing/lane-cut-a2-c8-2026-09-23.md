## Audit revision (second commit)

The orchestrator asked how `(:seon.error/at x)` differs from the deleted
`(inst? (:seon.error/at x))` guard. It does not: it is the same "is this any error"
discriminator, shorter. The first commit's 34 sites of that kind were therefore
reclassified: each was either deleted as propagation, or made to branch on a declared
member of the explicit union the value comes from. Script:
`tmp/cut-a2-c8/revise2.pl`. The structural residue (the q/pull/datoms guard heads and the
arity gate) was done by one hand perl pass.
