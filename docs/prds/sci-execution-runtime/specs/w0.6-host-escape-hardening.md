GOAL — no throw escapes the invocation path, nothing unbounded reaches a
frame or stdout, and the acceptor cannot die silently:
1. Frame safety: token-clip `:seon.error/message` (and any other unbounded
   error text) BEFORE framing, and move/guard the `settle!` frame write so
   a frame-encode/write failure settles the invocation as a bounded error
   frame instead of killing the pool task. The settle-once CAS semantics
   are preserved exactly. Same treatment for reader-loop `error-frame`
   sends.
2. Immortal acceptor: per-iteration catch in the accept loop with a fault
   record (the ONE `seon.error/record!` mechanism — no new log path);
   thread-start failure of one session never ends accepting; a
   startup-read timeout on new sessions so a connect-and-silence client
   cannot hold an unpooled thread forever (named-var default documented
   for the W1 config-fact relocation).
3. Session observability: the session-loop Throwable swallow records a
   fault instead of `nil` — same contract (session death remains the pod's
   child-exited signal), now visible. `serve-value-sample!` throws answer
   a bounded sample-error frame rather than killing the session (audit
   §4.4).
4. Print capture: bind sci's print machinery per invocation into a
   token-capped buffer feeding the EXISTING `::output` seam; overflow
   truncates with an honest marker; host stdout gets nothing from agent
   prints. `:seon.eval/output` appears on host evals for the first time —
   assert presence/shape, never wording.
5. Bounded realization in recording: `terminal-tx-data`'s full-value
   `pr-str` becomes a capped/counting writer so a huge value costs
   O(cap), not O(value). (The `wire-safe-value`/`bounded-result` transit
   probe realization is NOTED as a remaining weakness in your summary,
   not fixed here, unless you find a ≤10-line seam — report either way.)
6. Interrupt hygiene (audit §5.1): clear `Thread/interrupted`
   unconditionally before terminal recording and treat the flag itself as
   an interruption fact, closing the late-interrupt race (shared-channel
   kill + spurious next-form interrupt).
