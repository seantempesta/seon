## Goal

Every `:carried` operational key becomes `:enforced`: the writer (and
where applicable both transport peers) actually constructs its runtime
from the envelope values, and `config apply` reconstruction then covers
those keys automatically (W1.2a's boot-critical gate reads
`enforced-keys` — verify that flipping a disposition flips the gate, do
not build a second gate).

Surfaces, per the grounded report:

1. **Connection cap + UDS server options**: the writer currently does
   not pass them into `uds/start-request-server!`
   (`src/seon/db/writer.clj:4239-4245`); the envelope carries
   `:seon.config.database.transport/maximum-connections` (last
   observed value 272). Thread them from the envelope consumer
   (`src/seon/db/server.clj:382-430`) into the transport constructor.
   Cap rejections are steering error values naming the config key
   (owner ruling 7), never silent drops.
2. **Frame ceiling on both peers**: today a private protocol-derived
   constant on each side (`src/seon/db/transport/uds.cljc:166,221-256`;
   `src/seon/db/transport/uds.cljs:19`). Make it envelope/config-fact
   driven. MAP THE CONSUMERS FIRST: writer server, pod client, and the
   sci host's pool client (`src/seon/host/context.clj`) — if the host
   side has no honest config path (it is database-free by design),
   STOP AND REPORT with options rather than inventing a side channel.
   Peers must agree or negotiate; a mismatched frame ceiling must fail
   loudly at session open, not corrupt mid-stream.
3. **Executor-family capacities**: selected processors already flows
   into `executor/capacity` (`src/seon/db/writer.clj:4197-4201`);
   thread the remaining executor-family values the envelope carries.
4. **Codec workers/queue settings**: same pattern, into their owner.
5. **Flip dispositions** in `src/seon/config/resolve.cljc:163-166`
   (`enforced-keys`) key-by-key AS each surface lands, updating the
   per-key disposition the envelope records. The W1.2a decline test
   must flip to a reconstruction test for each newly enforced key.
