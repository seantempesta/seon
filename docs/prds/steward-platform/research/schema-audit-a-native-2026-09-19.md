The live development JVM does **not** instrument every first-party function. Of 3,573 bound nonmacro function Vars in 110 source-declared namespaces, 2,334 have no discoverable Malli contract (2,269 private, 65 public). ## Ranked findings

### A1 — Blocker: declaration coverage is absent from the arming guarantee

Live evidence above is direct. Denominator is **bound, fn?-valued, nonmacro Vars from ns-interns of namespace forms read from src .clj/.cljc files**, not a text/name-prefix approximation. All 110 discovered namespaces were loaded. It includes generated function Vars where fn? holds. It excludes macros, local closures, protocol methods/non-fn IFn objects, unloaded functions outside that population, test namespaces, and private SCI objects. It is not a complete census of logical program declarations. Contracted eligible nonprimitive denominator is 1,238; observed wrapper count is 1,238. That parity must never be presented as 3,573/3,573 coverage.

`src/seon/instrument.clj:67` defines armable using discoverable schema, bound Var, and nonprimitive root. `:848` collect-contracts! uses the same selection. `src/seon/test/arm.clj:170` arms loaded source namespaces and compares armable to instrumented, not every function to a contract-bearing declaration. Missing schemas never enter the comparison. This is the precise absence-as-health mechanism. Private selection itself now uses ns-interns and works; the problem is missing declarations, not continued public-only selection.

Existing class: [a database read's error value is read as a row by its caller](../../../seon/issues/a-database-reads-error-value-is-read-as-a-row-by-its-caller.md), **open/blocker**, includes the all-functions contract ruling and prior private-consumer census. Extend it with this dated evidence rather than minting one issue per function. Do not reuse its older raw-wrapper description without checking current record/panic behavior.

Invariant: every admitted first-party executable declaration has an honest contract, and every callable root requiring it is armed or has a positively recorded, justified non-callable classification. Missing schema and missing subject must be failures. Owner: program declaration/admission + instrumentation/test arming. Minimal falsifier: canonical harness contains one public and one private ordinary function with omitted contract; arming/publication must refuse with both identities, while declared functions arm and bad arguments never enter bodies. Add a generated-declaration classification case so machine-generated methods are not blindly treated as authored omissions. Partition repair work by namespaces **after** one shared coverage checker lands; no hand-maintained exemption roster.

### A2 — Blocker subtype: declared primitive function silently falls outside arming

Live sole contracted unwrapped row is `seon.sci.admit/required-cap`, defined at `src/seon/sci/admit.clj:696` with `^long`. Malli's primitive interface exclusion is explicit dependency behavior; Seon mirrors it at `src/seon/instrument.clj:52,67,848`. A declaration alone does not guarantee enforcement. Treat as A1's enforcement class, not a second general contract mechanism.

Invariant: agent/runtime-facing contracted callables cannot silently bypass validation through primitive compilation. Prefer an ordinary contracted boundary and a justified internal primitive implementation, or remove the primitive hint where unnecessary. Owner: SCI admission + instrumentation. Falsifier: invalid cap map/member passed through real acquired JVM and SCI routes must produce a typed contract refusal before function body work; current primitive function must appear in completeness reporting. No malformed call was run here.

### A3 — High priority source-derived gap: component ownership does not enforce semantic agreement of peer refs

`resources/seon/schemas/my.plan.edn:1,9,41` stores an identity-valued agent backlink and optional current-step ref; `resources/seon/schemas/seon.config.edn:1,17` similarly stores settings' agent backlink. Installed facts confirm both backlinks are cardinality-one unique identity refs. Their scalar type and uniqueness do not say they equal the parent reached through `:seon.agent/plan` or `:seon.agent/settings`.

Current writer's owning-value validation (`src/seon/db.clj:3485`) enforces component topology, child schema, cycles, multiple owners, missing child and traversal bound. Final chain (`:3854–3920`) additionally checks attribute types, agent retraction, deletion, render targets and arities. It does not compare these backlinks with their owning parent, nor require current-step to be an open descendant of that plan. The schemas are shape-only for these relations. `src/seon/agent.clj:82–98` correctly constructs a matching settings backlink, and `src/seon/plan.clj:1134–1142` rejects foreign/completed current steps in whole-plan construction. Correct constructors cannot prove arbitrary admitted final transactions safe.

**Not live-proven:** proposed counterexamples are source-derived and need canonical transaction tests before implementation. With two existing agents A/B and their valid settings SA/SB, swap both `:seon.config/agent` backlinks in one transaction while leaving component edges unchanged (retract both old unique datoms before adding swapped ones). Types, cardinality, uniqueness, schemas and component topology all remain valid; ownership claims disagree. Separately, set plan A's current-step to a valid open step of plan B. A plain ref makes the shape valid; the selection claim is wrong. Test no partial commit, not just API input rejection.

Prefer dissolving duplicate backlinks if addressability/rendering can derive identity through ownership; otherwise enforce equality at the one final-report authority. Current-step requires a final-state relation check including completion/reparenting changes, not only selection-time check. Owner: agent settings/plan schemas and final writer. Existing issue search found [plan item reads disagree with the owning plan](../../../seon/issues/archive/plan-item-reads-disagree-with-the-owning-plan.md), archived, but no open exact final-state relation class. Parent should consolidate a new issue only after the above falsifier.

### A4 — Contract completeness policy differs for core and agent declarations

`src/seon/schema/internal.cljc:188–218` applies undefined-slot refusal only when admission source is agent; core declarations receive advisory treatment at this seam. This is separate from legitimate named polymorphic values. In particular, a bare map contract can be perfectly valid for map operations but does not validate a domain record's required inputs. Replacing :any with :map mechanically does not achieve the user's guarantee.

Existing [anonymous runtime contracts have recurred](../../../seon/issues/anonymous-runtime-contracts-have-recurred.md) is **open/friction**, though much of its instance inventory is historical. Extend its class with exact current instances when closing namespace contracts; do not import its old counts. Invariant: one declared completeness policy across admitted production code, with explicitly justified polymorphic boundaries. Falsifier: identical incomplete authored contract through core publication and agent installation receives equivalent evidence; deliberate dynamic value boundary remains admitted. Owner: schema admission and program publication, serialized with A1's shared checker.

## Modeling corrections and retained guarantees

- Empty cardinality-many does not prove analysis occurred. Require an observation event/digest where absence must differ from examined-empty. Do not revive historical schema-key-audit's submission-only required-calls repair or retired-tx proposal: current policy uses analysis digests and retractEntity, with history/as-of for the past.
- Historical unbreakable-connections says several deletion/arity/render checks are missing and namespace-based acquisition is current. Today's final writer and per-row SCI admission have advanced. Its connection inventory is useful; dated counts and SILENT verdicts are not today's proof.
- The current generic component validator already handles identity-less owned children; do not add fake identities or another writer.
- Open maps are accretion, not a validation flaw. Query DSLs, arbitrary evaluation results, provider JSON, Flow dependency-native maps and effect evidence need their actual boundary grammar, not closed-record coercion.
- Source symbols, transaction provenance, bounded config dials, typed errors and declared component schemas in the assigned set are improvements to retain.
- `seon.agent/namespace` is installed as nonunique ref, so several agents can share a namespace already. `seon.ns/steward` remains cardinality-one. Changing the latter relationship requires reviewing assignment/routing/render consumers; renaming prose alone does not implement multiplicity.
- Assigned evaluation/AI-attempt schemas contain many independently optional outcome/evidence fields. This audit does not call all optional fields defects: pending/failed/interrupted/successful construction paths differ. A state-matrix pass must specify valid co-occurrence from settlement owners and final datoms before tightening. It must not infer successful completion from missing error.
- Documentation still contains older public-only contract wording and historical provisional modeling claims. Update skill/guide authorities with the coverage fix; do not follow those older statements over AGENTS' all-functions ruling.
