## Fix A — bounded source publication acquisition

Landed as `c8776fafe` (`Bound concurrent source publication`).

The unbounded monitor at `src/seon/cluster.clj` is now a `ReentrantLock.tryLock` acquisition. Its bound is derived from the existing operator lifecycle bound family through `seon.operator.state/event-silence-backstop-ms`, whose default is the database-backed `:seon.config.operator/event-silence-backstop-ms` fact. No new timeout constant or second configuration path was introduced.

The live holder record uses the operator lock vocabulary: process identity, command, phase, acquisition time, progress time, and acquisition timeout. Publication phase reporting advances that same record. A waiter that exhausts the acquisition bound receives `:seon.cluster/source-refresh-acquisition-timeout`, with a complete `:seon.error/message`, the holder and waiter records, holder phase, elapsed wait, and acquisition bound.

`test/seon/cluster/source_test.clj` now starts two real refresh requests on the canonical fixture. Latches and `seon.test-support/await-event!` hold the first request at the observable `bootstrap configuration` phase; the second request must either acquire and proceed within the bound or return the typed refusal naming that phase. The regression uses the fixture event backstop and contains no sleep.

## Fix B — refusal cause evidence and collection members

Landed as `940f4b426` (`Preserve refusal cause evidence`).

`src/seon/sci/eval.clj` now preserves a host namespace compilation failure through `seon.error/diagnostic`. The diagnostic identifies the acquisition layer, `seon.sci.eval/host-namespace!`, the namespace member, the underlying throwable, and known evidence. It walks to the deepest cause and carries its message plus compiler source, line, and column. The top-level `:seon.error/message` includes the cause and location, so an operator printer does not need special knowledge to reveal them.

`test/seon/sci/eval_test.clj` creates a classpath-visible namespace containing an unresolved var and verifies that `host-namespace!` refuses it with the underlying message and file/row evidence.

The collection wording seam was outside the held `src/seon/db.clj` transaction region. `src/seon/error.clj` now selects the failing member of homogeneous set, vector, and sequential schemas before describing the violation. A collection member failure therefore reports the member and its expected element form instead of the container-level contradiction “expected a set, got a set.” `test/seon/refusal_grammar_test.clj` covers the member wording.

## Fix C — canonical projection encoding dispatch

Landed as `dc63e6ebf` (`Accelerate canonical projection encoding`).

`src/seon/schema.clj` now dispatches vector, set, map, and sequential values before scalar EDN literal types. The protocol-backed `inst?` call was replaced by concrete checks for the host types that Clojure's `Inst` protocol extends and this encoder accepts: `java.util.Date` and `java.time.Instant`. Their existing epoch-millisecond encoding is unchanged.

`test/seon/schema_test.clj` retains the previous encoder as an oracle and checks 500 deterministic recursively generated values spanning every canonical population shape: nil, booleans, integers, ratios, strings, keywords, symbols, characters, dates, instants, UUIDs, vectors, lists, sets, and maps. Every generated byte string was identical.

One full canonical projection fingerprint measurement on the path-isolated fast harness covered 2,877 schemas and 1,193 contracts:

| Encoder | Elapsed |
|---|---:|
| Previous dispatch | 348.326 ms |
| Reordered dispatch | 36.885 ms |

That sample is 9.44× faster. The timing is recorded evidence, not a test threshold; the regression asserts only byte identity and fingerprint identity.
