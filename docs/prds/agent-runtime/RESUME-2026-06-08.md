## GOTCHAS (cost real debugging this session — honor them)

- `seon.db/transact!` is `^:async` → returns a **Promise**; you MUST `await`/`.then`
  it (a non-awaited transact silently doesn't commit before the next read).
- `seon.db/with-agent` takes a **bare STRING** agent-id, NOT a map. Passing a map
  stamps it as tx-meta `:seon.db/agent-id`, fails `string?`, and the whole tx is
  silently rejected behind an ok-ish envelope.
- Verifiers: do NOT `git stash` on STAGED files — it unstages them. Use
  `git worktree add /tmp/seon-head-X <commit>` to compare against HEAD.
- Don't drive live agent turns while an agent is mid-hot-reload of context code —
  you'd observe code in flux. Wait for the commit.
- datahike `:memory`: `:id` must be a real UUID (not a string), backend `:memory`.
