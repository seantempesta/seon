## Template for Findings

Each research document should include:

1. **Objective** - What question was being answered
2. **Methodology** - How the research was conducted
3. **Findings** - What was discovered (with code examples)
4. **Implications** - What this means for the project
5. **Recommendations** - Suggested next steps
