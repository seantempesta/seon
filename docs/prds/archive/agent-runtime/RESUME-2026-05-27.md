### IMMEDIATE PRIORITY: Wave 4.5 Item E — MCP eval routing by agent-id

**Why this jumped the queue:** without it, you can't query/inspect a running agent's state from outside. The MCP server today knows `"orchestrator"` and legacy 4-char hex agent-pool ids — it has no way to address a V2 agent or session. Result: no way to verify multi-agent + multi-session behavior end-to-end without reading raw DB rows. The user said: *"It's a priority actually as you can't properly test things without this."*

**Spec:** see [[execution-waves-2026-05-26#Item E — MCP eval routing by agent-id]]. ~80 LOC + tests + doc.

**Shape (brief):**

- Agent-id is the unique key. Each agent → one session by construction.
- `mcp__seon__eval session_id=":seon.agent/<id>"` wraps user code in `(seon.session/with-agent <id> (do <user-code>))` and sends to master nREPL.
- `with-agent` resolves agent-id → session-id → conn, binds `*conn*` + `*current-agent-id*` for the body.
- The eval runs JVM-side; wasm guest hosting the agent is undisturbed.
- Wasm-guest eval (CLJS inside wasm) is a SEPARATE, harder problem; deferred from MVP.

**Tests required:** end-to-end smoke — two sessions × two agents, eval scoped to each agent-id, verify datoms land in the right session's DB.

## Locked terminology (2026-05-27)

See [[integration-architecture-2026-05-26#2. Definitions (precise — locked 2026-05-27)]]. Highlights:

- **session** = DB + storage + wire-server socket pair (`:seon.session/<name>`).
- **agent** = one wasm runtime joining a session (`:seon.agent/<id>`).
- **seon** = THE seon JVM Clojure system.
- **wire-server** = UDS server in `src/seon/server/`.
- **host** = Rust binary (was "rust-host"); to be moved to `host/` in Wave 6.
- **shell** = future Tauri packaging wrapping `host`.

**Retired:** "sidecar", "PoC", "pod" (V0-only), "platform" (as a directory name), "jvm-writer", "rust-host".

## Operational gotchas (carried forward)

1. **`(in-ns ...)` wedges the MCP REPL.** Three agents have hit it across Waves 1a, 2a, 3a. Recovery: `bin/seon restart jvm`. Hard rule: use fully-qualified symbols or wrap multi-form work in one `(do ...)` inside one `mcp__seon__eval`.
2. **`Edit replace_all` may be lint-blocked** for multi-instance keyword-namespace renames (hook lints pre-edit state). Workaround: `sed -i ''`.
3. **MCP server orphan accumulation** — fixed in `bin/mcp-server`/`bin/mcp-server-cljs` (parent-watchdog, `b0b0f65`).
4. **The hook flags `deftest` forms** as "missing `:malli/schema`" — false positive. Ignore.
5. **`:sqlite` backend isn't fully wired.** konserve-jdbc 0.2.91 doesn't register on konserve 0.9.340's dispatch multimethod. MVP uses `:file`. TODO comment in `src/seon/server/store.clj`. See architecture doc §4.
