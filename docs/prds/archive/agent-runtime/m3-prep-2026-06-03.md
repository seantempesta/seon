### 2a. Register the data-boundary Malli schemas (in `reactive.clj`)

These are the durable subscription entity + the ephemeral event shape. The
engine already *emits* and *transacts* these maps; today nothing registers them,
so `transact!`-style validation can't fire and instrumentation has no contract.
Add to `reactive.clj` (it owns this data boundary per the lane split). **Testable
now** via `m/validate` round-trips on hand-built maps + the engine's own output.

```clojure
;; --- shared shapes (register once) ---
(schema/register! :seon.subscription/id   [:string {:min 1 :seon.db/identity true}])
(schema/register! :seon.subscription/query :string)                 ; source string (code-as-data)
(schema/register! :seon.subscription/active? :boolean)
(schema/register! :seon.server.reactive/basis-t  [:int {:min 0}])

;; render-fn + agent refs DEPEND on :seon.agent/id (platform, DONE registry.clj:103)
;; and on :seon.fn/sym (mine, 2b). Register these AFTER requiring registry so
;; :seon.agent/id exists, and AFTER 2b registers :seon.fn.
(schema/register! :seon.subscription/agent     :seon.db/ref)        ; → the owning agent
(schema/register! :seon.subscription/render-fn :seon.db/ref)        ; → a :seon.fn entity

;; --- the durable subscription entity ---
(schema/register! :seon.subscription/entity
  [:map
   [:seon.subscription/id        :seon.subscription/id]
   [:seon.subscription/agent     :seon.subscription/agent]
   [:seon.subscription/query     :seon.subscription/query]
   [:seon.subscription/render-fn {:optional true} :seon.subscription/render-fn]
   [:seon.subscription/active?   :boolean]
   [:seon.subscription/basis-t   {:optional true} :seon.server.reactive/basis-t]])

;; --- the ephemeral changed-summaries event (NOT a datom — wire payload) ---
;; the `rows` :any decision: PRD §9 + review issue 4 bank it. Recommend the
;; scalar-union for the non-pull case; ship coarse `[:vector :any]` only if the
;; union is too tight for real query rows (decision for Sean — see Q1 below).
(schema/register! :seon.server.reactive/scalar
  [:or :string :int :boolean :keyword :inst :uuid :double])
(schema/register! :seon.server.reactive/rows
  [:vector [:vector :seon.server.reactive/scalar]])                        ; tuples; tighten/relax per Q1
(schema/register! :seon.server.reactive/changed-entry
  [:map
   [:seon.agent/id          :seon.agent/id]
   [:seon.subscription/id   :seon.subscription/id]
   [:seon.server.reactive/rows     :seon.server.reactive/rows]
   [:seon.render/ai   {:optional true} :seon.render/ai]
   [:seon.render/html {:optional true} :seon.render/html]])
(schema/register! :seon.server.reactive/changed-summaries-event
  [:map
   [:seon.server.reactive/db-name :seon.server.reactive/db-name]
   [:seon.server.reactive/basis-t     :seon.server.reactive/basis-t]
   [:seon.server.reactive/request-id  {:optional true} :string]
   [:seon.server.reactive/changed     [:vector :seon.server.reactive/changed-entry]]])

```

**Dependency note:** `:seon.subscription/agent`, `:seon.subscription/render-fn`,
`:seon.server.reactive/changed-entry` reference `:seon.agent/id` (platform, DONE) and

add a `(:require [seon.server.registry])` so `:seon.agent/id` is registered before

**Schema-shape mismatch to fix while here:** today `on-tx!` emits
`{:seon.server.reactive/db-name … :seon.server.reactive/basis-t … :seon.server.reactive/changed [{:seon.server.reactive/sub-id :seon.server.reactive/result}]}`
(`reactive.clj:206,218`). The PRD/event schema above uses

engine's raw `{sub-id, result}` into the registered `changed-entry` shape

### 2d. Pure handler logic + event-builder (independent of wire dispatch)

Write these as **pure functions in `reactive.clj`** that take a resolved `conn` +
a parsed request map and return a response map — so they are testable by direct
call, with **no** `handle-op`/socket/wire-dispatch dependency. The thin
`handle-op "register-subscription"` method (which resolves the conn and Transit-
decodes) is the *only* part gated on platform; it becomes a 3-line wrapper.

```clojure
;; register-subscription core (engine already has register-subscription!,
;; reactive.clj:154 — this wraps it with the wire response shape):
(defn handle-register-subscription
  "Pure over a resolved conn + engine state. Persists the sub datom, derives
   patterns, registers in cache+index AFTER the tx (so it doesn't self-route),
   returns {subscription-id basis-t patterns rows}. Headless-testable."
  [{:keys [state conn sub-id query agent-id render-fn]}]
  (let [entry (register-subscription! state conn sub-id query)   ; reactive.clj:154
        db    (d/db conn)]
    {:seon.subscription/id sub-id
     :seon.server.reactive/basis-t (:max-tx db)
     :seon.server.reactive/patterns (:patterns entry)
     :seon.server.reactive/rows (:last-result entry)}))

;; unregister-subscription core: retract :active?, drop from cache+index.
(defn handle-unregister-subscription [{:keys [state conn sub-id]}]
  (d/transact conn [[:db/retract [:seon.subscription/id sub-id]
                     :seon.subscription/active? true]])
  (unregister-sub! state sub-id)                                  ; reactive.clj:138
  {:seon.subscription/id sub-id :seon.subscription/active? false})

;; changed-summaries event-builder: maps the engine's raw emit (sub-id+result)
;; into the registered changed-entry shape. Resolves agent-id per sub from the
;; sub datom (:seon.subscription/agent → :seon.agent/id). Pure given a db + the
;; raw `changed` vector — THIS is where 2a's shape reconciliation happens.
(defn build-changed-summaries-event [db db-name basis-t request-id raw-changed] ...)

```

**Testable now:** 2d's three fns run against a fresh `:memory` conn (the
`with-engine` harness, `reactive_test.clj:11`, already gives one) with
`:schema-flexibility :read` so no datahike schema-install is needed yet. Assert:
register persists the datom + returns rows + does not self-route (mirrors
`persistence-and-register-after-tx`, `reactive_test.clj:87`); unregister flips
`:active?` and drops from the index; the event-builder produces a map that
`m/validate`s against `:seon.server.reactive/changed-summaries-event`.

## 5. Open questions / risks

**Decisions (RESOLVED 2026-06-03 — applied in `reactive.clj`, commit 36e12b2):**

- **Q1 — the `rows` `:any`. RESOLVED: scalar-union.** `:seon.server.reactive/rows`
  = `[:vector [:vector :seon.server.reactive/scalar]]` with `:seon.server.reactive/scalar`
  = `[:or :string :int :boolean :keyword :inst :uuid :double]`, for `:find`-tuple
  queries. It is an *ephemeral wire payload*, not a persisted datom. Pull-shaped
  rows (maps/nested) are deferred — extend if a real query row fails validation.
- **Q2 — engine emit shape. RESOLVED: match, no translation.** The engine emits
  the registered shape directly — `{:seon.subscription/id, :seon.server.reactive/rows}`
