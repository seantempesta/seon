**Design, simplest kill first.** `seon.test/verified?` (`test.clj:407`) already requires a source-bearing subject, positive passes, zero failures/errors, a run identity and exact **whole-program** digest; missing evidence is false and refusals are errors. It checks only the latest result, does not select work, and does not distinguish cold-gate evidence from in-process evidence. `program-digest` (`runner.clj:1358`) identifies the source seal plus changed canonical program rows, not a test closure. `record-tx` (`:1420`) replaces latest results; `source/record-results!` preserves original provenance when advancing current-src (`cluster/source.clj:297`). Neither `basis-t` nor git SHA alone identifies tested bytes across isolated stores/overlays. Never apply an isolated run's basis to current-src's history.

1. **Delete duplicate full-run admission.** Before snapshot/worker preparation, query recorded coverage for the exact immutable requested snapshot and full-run mode. A completed red run answers the request too: print its reds, do not replay them to rediscover them. Missing/unexecuted tests remain outstanding, never green. Keep the existing slot owner and worker cap (three by default, `bin/test:681`); the Opus thread is orchestration policy, not inferred from an environment flag. Record execution mode, requested scope, terminal completion and tested snapshot as run provenance through the existing writer, so partial/platform/in-process runs cannot impersonate full coverage. A killed thread reports; it does not relaunch. `--full` includes long tests; `--all` is not a full-suite claim.
2. **Replace file-basis selection with derived per-test content identity.** On one immutable program value, normalize identities/refs and hash each reachable declaration once, including source, spec, call edges, subject, namespace declaration, fixture setup and schema dependencies. Derive strongly connected components once and carry their hashes through the closure graph; store no current-digest map, closure roster or second green-basis file. Include conservative shared input identity for dependency revisions, harness/arming code, schema/config resources and non-call setup forms. Dynamic resolution, missing edges, unsupported setup or missing subjects mean unknown → execute. Namespace `:once` fixtures and `test-ns-hook` remain atomic (`runner.clj:630`; Clojure `test-vars`, `reference-code/clojure/src/clj/clojure/test.clj:726`). A change outside a complete closure preserves its digest; a change inside invalidates it. An unknown global input invalidates all affected proofs.
3. **Carry the tested identity into existing result recording.** Recommend a new historical **tested-reach digest** on the result, computed before execution from its immutable admitted program, plus cold/in-process execution provenance. This records what was tested; it is not a stored mirror of today's derivable digest. Keep `:seon.test.run/program-digest` whole-program semantics unchanged. Extend source evidence preservation and total result replacement together. Reuse only the latest complete cold green matching current derived reach and shared inputs; a later red cannot be hidden by an older green. Do not rebuild old databases or reread historical manifests on each gate.

**Owner decision before implementation:** (A) **recommended**, historical tested-reach attestation in the existing result, current reach always derived: roughly two implementation slices (selection/admission; recording/schema/regressions), permits cross-HEAD reuse, gives up recovering overwritten greens; (B) existing whole-program digest only: one smaller admission slice, safe same-snapshot reuse, gives up the 73 cross-program candidates; (C) retain exact tested program commits and derive both closures on demand: additional cross-store retention/GC work plus repeated derivation, no per-result reach attestation, gives up the cheap lookup. Datahike already loads immutable commits (`reference-code/datahike/src/datahike/versioning.cljc:469`); an isolated store's deleted commit is not recoverable merely because its branch/basis was recorded. Estimates are scope prices, not measured durations.
