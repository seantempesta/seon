## Verdict

Revise before implementation. The strongest simplifications are selected-path observation, removing manifest readback, carrying the existing projection, identity-derived tempids, and ordinary prepl commands. The first pass instead spends several guarantees to obtain its size and speed estimates: writer-basis reconciliation, actual development adoption, cache ownership, complete resolver identity, schema-dependent arming and final-report admission.
