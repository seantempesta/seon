## Proposed rewrites

The following blocks are exact replacement text for the named sections or rows; they replace inconsistent claims in the owner opening and done criteria as well.

### Replace §0's “simpler way” paragraph and §2 (including “Trust boundary”)

One admitted projection carries compiled schemas. Ordinary reads reuse it. Cold acquisition reads the exact database program once; updates reuse unaffected compiled objects. A small compilation count does not prove a small update: today registry assembly still walks and copies the population. This lane measures and removes that work where Malli's persistent registry representation already suffices.

| Mechanism | Data, time and carrier | Trigger and work |
|---|---|---|
| Generation | Forms, contracts, dependency maps and compiled schemas carried by the immutable database value and context | Cold: full population. Update: changed declarations plus reverse dependents compile; pass those identities to preparation. Probe `mr/simple-registry` over the updated persistent map (`registry.cljc:24-28`) to remove `HashMap.putAll` and whole-population selection (`schema.clj:465-503`). Count visited/copied entries; do not claim O(change) while they remain. |
| Shape projections | Required-attribute maps, shape index and catalog on the projection | Currently full shape-row processing (`schema.clj:2201-2235`). Probe updates to these existing values from replaced rows; sorting the full catalog remains an explicit cost until removed. |
| Acquisition | Read the projection through the database owner's origin-aware seam (`db.clj:1156-1170,1219-1225`) | Ordinary DB: metadata read; temporal DB: origin traversal. Absence in running code refuses. Named cold acquisition reconstructs only from the exact supplied database, never the current classpath as a substitute. |
| Arming | Retained contracts, declared output schemas and policy in callable closures; unchanged wrappers retain identity | Compilation: zero named declarations. Selection currently visits loaded contracted Vars and their dependency maps; publication's affected identities may bound selection. A shared JVM Var has no per-cluster generation: deleting its projection selection requires the two-generation proof below. SCI context-owned roots already have an ownership seam. |

| Admission | Prospective declarations/deletions plus the carried projection produce findings | Cold: all declarations. Edit: changed declarations and affected dependents validate. ### Replace A1-1's dispatch instruction, the trust claim, and §6 C4

Read contracts through `mr/schema`; preserve non-returning rejection and boundary settlement. Malli's `:report` return value does not stop invocation (`core.cljc:2210-2215`). Its multi-arity wrapper sends the same original function to every child (`:2279-2282`), but the existing `:gen` option receives each child schema when its callable is constructed (`:2207`). Probe passing a `:gen` function which captures that child's declared output permission and the original callable, returning the callable that checks its result. Malli then owns arity dispatch and Seon's second scan disappears; no new dispatch or fork API is needed. Verify invalid input without body invocation, invalid arity, undeclared error output, and an error satisfying both declared and additional open schemas before deleting the old scan.

Before deleting host projection selection, verify two different projections calling the same loaded JVM Var in both orders, including different contracts and fault policies. Keep the existing host behavior if the proof fails; this does not block reading retained contracts or deleting the dead digest. Context-owned interpreted wrappers close over their projection using existing SCI ownership; a global Var does not become cluster-owned by assertion. Preserve the predicate-binding/compilation recursion behavior until retained predicate roots are verified too (`instrument.clj:742-754,882`).

### Replace A1-2/A1-2b/A1-3/A1-8 ordering paragraphs and §5b's “without an edit” claims

Land the acquisition-owner conversions and changed seam together. The conversion set includes every two-argument call in SCI and turn acquisition, commit-value acquisition in `db/carry-derived-projection`, publication/boot readers, and the runner's deliberate reconstruction. Verify that each post-write database carries the admitted post-write projection and that retained older values keep their earlier projection. Do not substitute carried metadata until this invariant is proven. Avoid a `schema` → `db` require cycle; use the existing late-resolution idiom for that boundary.

Retire the two-argument acquisition arity, zero-argument declaration constructor, SHA helpers, or admission CLI only in the commit converting every caller, including tests. Until the owning files are available, keep the existing API and land independent internal reductions. A1-8's CLI retirement and B1's hook conversion are one slice. Admission must subtract declarations removed from edited files and recompile affected dependents; a composite registry containing old compiled dependents does not do this automatically. Config-display validation runs at admitted construction for both initial and changed declarations, using already compiled properties; registration alone is not complete coverage.

Every implementation commit reloads the touched namespaces on default under the owner's adoption workflow and records a successful bounded `runtime_status` read. Cold-load proof is additional, not a substitute. A lane never resets default. The orchestrator batches marked RESET changes using `bin/seon reset --force`; disposable database contents and in-memory agent objects are lost and fixture data is reseeded. The REPL-first recovery path remains available for diagnosis.

### Replace A1-5 and §6 C1/C2

Build plans from retained compiled contracts. Match a supplied default only at its declared schema name; two schemas with identical bodies remain different names. Inspect reference identity before dereferencing to inspect map entries. Preserve the required entry-key match, optionality, explicit caller values, fixed-arity precedence, ambiguous placement refusal and existing variadic behavior. Handle `:catn` and regex input nodes through their compiled structure; `m/children` is not uniformly a vector of positional schemas.

Supplier coherence and `named-entry-facts` currently also query shape rows (`call_preparation.clj:424-499`); convert them before claiming zero shape-row reads. A newer database basis alone does not rebuild plans: retain the existing snapshot's plans when supplier facts and retained contracts are unchanged. Probe initial acquisition, unrelated transactions, supplier changes, contract changes, and two distinct names sharing the same form. Record declarations visited and plans constructed, not “tens of symbols” or guessed milliseconds.

## Verdict

Revise before implementation. Reading retained contracts and removing repeated acquisition are sound directions, but this draft mistakes bounded compilation for bounded processing and moves new population work into snapshot refresh. Name-based suppliers, persistent registry updates, and retaining already-derived products offer the clearest reductions. Shared-Var custody, AST/codec compatibility, prospective admission and atomic caller conversion are correctness prerequisites. The size target is plausible as an aspiration but not yet supported by the listed deletions; the replacements above make the missing proofs and ownership boundaries explicit without adding a mechanism.
