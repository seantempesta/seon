# The one REPL path: spec and instructions

## 0. Answer

**Summary.** One read of one form at a time. SCI evaluates it once. Every definition is observed at the `def` and its
contract is armed before the next expression runs. kondo analyzes the batch once, and each observed definition joins at
most one kondo definition by an exact rule. Program rows are derived from that one analysis and settle in one
transaction. The reply keeps every value. The whole pipeline was built and run at default's REPL.

**How observation works.** SCI already offers the seam for definition-time observation: a watch on the context's env
atom, the owner of every namespace-map mutation. It needs no fork change. One SCI fork change is still needed, a
one-line patch, so that definitions generated inside nested macro expansions carry their macro call's location, as
Clojure's compiler does. Across the corpus the patch changes exactly those 10 items, and SCI's own suites show no
regression.

**Speed.** Measured warm on default:

| Batch | Prototype | Today |
|---|---|---|
| One contracted `defn` | 35 ms (p50 91 ms over the 40 corpus items that write rows) | 512–948 ms |
| Each further `defn` in the same batch | ~10 ms | — |
| 22 registrations (h36) | 340–454 ms | 50.8–54.7 s (measured today on a branch) |
| Two defns in one `let` (h39) | 40–94 ms | 309–342 ms |

Allocation is 51 MB for a one-defn batch and 739 MB for h36. Nearly all of h36's is schema-projection building.

**Corpus.** All 94 items pass: every value equals plain SCI's or differs by design (§6.2). No commit was refused.
81 definitions join exactly without the SCI patch. With it, 14 more do (proven). That leaves 7:

- 5 are SCI's internal `__->R__ctor__` helpers. They sit at the origin of a matched `defrecord` and belong to it.
- 2 (h40) are generated by an agent-defined macro that kondo does not expand. Their values are right; they stay
  private until Q1. A kondo hook that closes them was proven.

**Instructions.** 18 steps. Net production change is about **−1,600 lines** without Q2, or about **−2,120** with
Q2's recommended answer. Tests net about −350 with Q2's recommendation and about +130 without it (§7.3).

**Owner questions.** Five, with priced options (§10). Two of them answer root's in-flight findings: the lone schema
key (Q4) and the MCP double print (§5, entrant 2).

## 1. What exists, and what replaces it

**Today.** Text goes to `cluster.reply/sources`, which reads, predicts namespaces and classifies prose. Then
`turn/evaluate-sources` loops per form into `sci.eval/evaluate`. That function reads the form again. After the form it
admits one declaration: it diffs a snapshot, runs kondo on that form, and matches by position. It gates each
declaration on a disposable branch and builds a speculative `with-settled` database per row. `settle-batch!` then
analyzes each declaration again inside the writer. Finally MCP reads the observation back and prints it a second time.

**Target.** Text goes to `sci.eval/evaluate-batch`, and each later stage runs once:

1. One reader cursor under SCI's live resolver. SCI evaluates each form once.
2. The env watch observes every bind and arms its contract at the `def`. The registration delta is always bound.
3. `fn/batch-rows` runs kondo once over the batch.
4. `fn/join-binds` joins exactly.
5. The gate runs on the completed candidate.
6. `settle-batch!` writes one transaction. The writer runs `row-tx` per row and never analyzes again.
7. Each entry's shown text, printed once, is the reply.

beside `:seon.eval/shown` and `:seon.eval/duration-ms`, which it reuses. None of the new keys collides with an
existing registry key. Live objects (the SCI Var, the value) are held only inside the call. Stored facts come from the
rows and receipts the settlement writes.

**Stage 1, `evaluate-batch`.** Acquires the program once. Binds the registration delta. Runs one source reader over
the input's code ranges, skipping whitespace, comments and Markdown fences. Each form is read under SCI's live resolver
with Seon's reader policy (`seon.sci.reader/parse-options`), then evaluated by stage 1b. It installs the observer (1a),
arming every bound function under the batch's candidate projection.

**Stage 2, `batch-rows`.** One kondo run over the batch. Each top-level form is a request in the namespace SCI started
it in, with SCI's live aliases. Every Var the batch bound is declared in the prelude. The builder is the existing one:
`analysis-entities-by-file`, `declaration-row` and the definition digest. Rows are keyed by form index, UTF-8 offset in
the form, and name.

**Stage 4, `batch-program-rows`.** A matched bind whose SCI root is a function or a test Var becomes a row carrying
the Var's evaluated `:malli/schema` as `:seon.fn/spec`. Every other bind is `:seon.eval/private`: data, atom, MultiFn,
protocol, defonce. The batch's schema rows come from `schema/changed-keys` of the delta, under one candidate
projection built once from the final forms. Removal rows come from `:unmap` effects of stored identities. The existing
reader fallback goes.

**Stage 5, `gate-batch`.** Entry policy on the completed candidate:

- A function row without a contract is a diagnostic. Its Var's root is reverted to the base context's root, or the
  Var is unmapped if it is new. This keeps the standing rule that a refused program change never survives as a private
  binding.
- The auto-check runs in a `sci/fork` of the batch context, with the candidate database value as read-only custody.
- Gate tests whose bodies write run on one branch per batch through the existing agent entrance.

A gate refusal is a diagnostic. It never replaces a value.

## 4. The join, proven

**The rule** (prototype `join` plus the re-analysis block in `derive-rows`). A Var's final bind has origin *o*, the
Var's `:line`/`:column`, in form *i*. Its candidates are the kondo definitions of the same name that either:

- **(a)** start at *o*, meaning they are the definition form that ran; or
- **(b)** lie inside the call form that kondo's usage places at *o*, and are defined by that call's own operator
  (`:defined-by` = the usage's `:to`/`:name`). Protocol methods and record constructors are the cases.

Exactly one candidate is `:matched`. None is `:unanalyzed`, with its reason:

- `:runtime-origin` when the Var has no location (an `intern` or `eval`);
- `:no-definition-at-origin` otherwise.

An unanalyzed bind at the origin of a matched declaration is a `:companion`, for example SCI's `__->R__ctor__`.
Several candidates would be `:ambiguous`; the corpus produced none. The namespace is always SCI's. If kondo placed the
matched definition in another namespace (a namespace change inside its own top-level form), that definition's exact
span is analyzed again as its own request in SCI's namespace. Every Var the batch bound is declared in kondo's prelude,
so calls resolve to the Vars that ran.

**Why it is exact, not heuristic.**

- SCI sets a Var's location from the reader metadata of the `def` node that executed. With step S1, a node the reader
  never saw takes the location of the innermost authored macro call whose expansion produced it; without S1 it takes
  the top-level form's (`analyzer.cljc:859-869`).
- kondo's definitions carry the start of their own defining form. Its usages carry the full span of every call form
  (probe: `defprotocol` 1:1–1:25, `defpair` 3:4–3:13).
- So (a) is equality of the position of one syntax occurrence. (b) is containment in one call form's exact span,
  restricted to definitions that form's own operator declares.
- A definition that did not run produces no bind: a false branch, an uncalled body, a second `defonce`. Its kondo entry
  is never selected. Proven: `(when false (defn z …))` and `opz` made no row.
- Only a bind is ever joined, so there is no position arithmetic and no name search.

**Proof on the corpus.**

| Case | Evidence |
|---|---|
| Authored `defn`/`def`/`defmacro`/`defmulti`/`defprotocol`/`defrecord`/`deftype` at top level, in `do`, and through a `do`-expanding macro | 81 of 81 binds matched (§6.2) |
| Nested in `let`/`when` | Pinned SCI puts the Var at the top-level form. S1 moves exactly these 10 items to the call's own column: 17 in `let`, 12 in `when` (`locs-orig.edn` vs `locs-patched.edn`, diffed; no other item's location changed). The join over the patched origins matched all 14 binds, including `defprotocol` methods through rule (b). |
| Two contracted defns in one `let` (h39, corpus F4) | Both matched and both rows committed in one transaction |
| Same name defined twice in one form | The final Var metadata names the occurrence that ran last. Redefinition probe: `g` armed again at line 4. |
| Nested `in-ns` then a `defn` in the same form | Before the fix, the row came out as `user/nf` for `op.nested/nf`. After the declared prelude and span re-analysis: `op.nested/nf`, `nf2` calls `op.nested/nf`, and computed `(in-ns n)` inside `let` stays `user/cf`, as in Clojure. |
| Runtime `intern` | Bound with no location, so `:runtime-origin`. No static fact is asserted. |

**Where the join cannot be made from the original text, and what replaces it.**

1. **A definition generated by an agent-defined macro kondo does not expand** (h40). Values are right; the two Vars
   are private. Q1 closes this with kondo's own `:macroexpand` hook, an existing kondo mechanism (`hooks.clj:253`,
   string hooks at `core.clj:224`). Proven: fed h40's `defmacro` source, kondo reports `h40-x` and `h40-y` at 4:1,
   defined by `clojure.core/defn`, which is exactly SCI's origin.
2. **Closure capture.** `(let [k 1] (defn f [x] (+ k x)))` is live and armed. Its row's source is the def's span.
   Reacquiring it from that span alone cannot reconstruct `k`. This is Astra §5.4 counterexample 4, unchanged: write-back
   of such a row must refuse honestly (kondo reports `k` unresolved in the span), never replay the enclosing form.
3. **`definterface`.** SCI does not implement it; plain SCI fails the same way.

**Answer to root: the exact MCP reply projection (both modes).** An MCP reply is the JSON array of the batch's entries.
Each entry maps to:

```clojure
{"tag" "ret"
 "val" <:seon.eval/shown: the one print, by the declared renderer or the floor>
 "seon.cluster.eval/ordinal" n
 "seon.turn/id" id                      ; SCI mode with custody

```

The rules:

- `val` is the floor's text as a JSON string. It is never `pr-str` of a map holding printed text, and never an EDN
  re-read and re-print.
- Today's double print comes from two places, and both are deleted in S15:
  - SCI mode: `run-events` (mcp.clj:449) reads the terminal EDN back and emits `:seon.repl/response`.
  - JVM mode: `cluster/mcp-project` (cluster.clj:352) returns the floor's prepared value inside
    `{:seon.dev.mcp/value …}`, and the prepl prints that map.

**Answer to root: the lone-key rule for `register!`.**

- A registered key is a stored attribute exactly when an entity map with `:seon.db/attributes` in the batch's candidate
  projection lists it (`schema.datahike/database-attributes-in`).
- Every changed key's registration answers `:seon.schema/stored?` in the batch's `:seon.eval/schema-notes`, beside its
  value. Proven: h16's `:corpus.h16/n [:int]` reports `stored? false`, correctly, because it is a value schema used by a
  contract.
- A later write naming an unstored key refuses at the writer, naming the key and this rule.
- Whether registration should instead refuse loudly is Q4.

(defn- candidate-projection
  "The batch projection: the database's plus the delta's changed keys, as ONE
  derivation (projection-with-declarations over the final forms), memoized on
  the batch by the delta's forms value."
  [{:keys [db delta memo]}]

        changed (schema/changed-keys delta)
        forms @(:seon.schema.delta/candidate-forms delta)

                (if (empty? changed)
                  base
                  (#'schema/projection-with-declarations
                   'pipeline/candidate-projection base
                   (select-keys forms (keys forms))
                   (get base :seon.schema.projection/function-contracts {})

                          :seon.schema/schema-admissions
                          (into (:seon.schema.projection/schema-admissions base)
                                (map (fn [k] [k {:seon.schema.admission/source :agent}]))
                                (filter #(contains? forms %) changed))))))]
    (if memo
      (let [[k v] @memo]
        (if (identical? k forms) v (let [v (build)] (vreset! memo [forms v]) v)))

(defn- sci-var? [v] (instance? sci.lang.Var v))

(defn- var-symbol [v]
  (let [m (meta v)] (symbol (str (:ns m)) (str (:name m)))))

(defn- observe!
  "Watch the ctx's env atom (SCI's one mutation owner for namespace maps).
  A Var that appears in a changed namespace map is held; on every env swap a
  held Var whose root is not the one last seen is a bind: `on-bind` runs with
  it on the evaluating thread before `def` returns (eval-def swaps the env
  after binding root and metadata, sci/impl/evaluator.cljc:25-49), so the next
  expression of the same form already calls the armed root. Removed Vars and
  namespaces are recorded too. `form-ordinal` is a thunk naming the form being
  evaluated. Answers a stop thunk returning the ordered effects."
  [ctx form-ordinal on-bind]
  (let [state (volatile! {:held #{} :roots {} :effects []})
        record! (fn [effect] (vswap! state update :effects conj (assoc effect :ordinal (form-ordinal))))
        check! (fn [v]
                 (when (sci.vars/hasRoot v)
                   (let [root (.getRawRoot ^sci.lang.Var v)]
                     (when-not (identical? root (get (:roots @state) v ::none))
                       ;; Total: an arming failure never escapes the def and
                       ;; never leaves the function callable unarmed.
                       (let [[armed failure]
                             (try [(on-bind v) nil]
                                  (catch Throwable t
                                    (let [refusal (ex-info (str (var-symbol v) " is unavailable: its contract did not arm: "
                                                                (ex-message t))
                                                           {:seon.error/member :seon.fn/spec :seon.fn/sym (var-symbol v)} t)
                                          refusing (fn [& _] (throw refusal))]
                                      (sci.vars/bindRoot v refusing)
                                      [refusing (ex-message refusal)])))]
                         (vswap! state update :roots assoc v (or armed root))
                         (record! (cond-> {:effect :bind :var v :sym (var-symbol v)
                                           :origin (select-keys (meta v) [:line :column])}
                                    failure (assoc :arm-error failure))))))))]
    (add-watch (:env ctx) ::observe
               (fn [_ _ old-env new-env]
                 (let [old-nss (:namespaces old-env) new-nss (:namespaces new-env)]
                   (when-not (identical? old-nss new-nss)
                     (doseq [[n m] new-nss
                             :let [om (get old-nss n)]
                             :when (not (identical? m om))]
                       (doseq [[k v] m
                               :when (and (symbol? k) (sci-var? v) (not (identical? v (get om k))))]
                         (vswap! state update :held conj v))
                       (doseq [[k v] om
                               :when (and (symbol? k) (sci-var? v) (not (contains? m k)))]
                         (record! {:effect :unmap :sym (symbol (str n) (str k))})))
                     (doseq [[n _] old-nss :when (not (contains? new-nss n))]
                       (record! {:effect :remove-ns :ns n})))
                   (run! check! (:held @state)))))
    (fn stop [] (remove-watch (:env ctx) ::observe) (:effects @state))))

(defn- skip-blank!
  "Advance the source reader over whitespace, commas and ; comments."
  [rdr]
  (loop []
    (let [c (rt/peek-char rdr)]
      (cond
        (nil? c) nil
        (or (Character/isWhitespace (char c)) (= \, c)) (do (rt/read-char rdr) (recur))
        (= \; c) (do (loop [] (let [d (rt/read-char rdr)] (when-not (or (nil? d) (= \newline d)) (recur))))
                     (recur))
        :else nil))))

(defn- read-evaluate-loop
  [{:keys [ctx text start-ns]} ordinal]
  (let [starts (line-starts text)
        n (count text)
        rdr (sci/source-reader text)
        ;; Seon's one reader policy (declared tags, no #=) over SCI's live resolver.
        options (#'reader/parse-options
                 {::reader/ctx ctx ::reader/features #{:clj} ::reader/tags {}})
        eof (:eof options)]
    (sci/binding [sci/ns (sci/create-ns start-ns)]
      (loop [entries []]
        (skip-blank! rdr)
        (let [line (sci/get-line-number rdr) column (sci/get-column-number rdr)
              start (char-offset starts n line column)
              ns-before (sci/eval-form ctx '(ns-name *ns*))
              read-result (try {:form (sci/parse-next ctx rdr options)}
                               (catch Throwable t {:read-error (ex-message t)}))]
          (cond
            (= eof (:form read-result)) entries
            (:read-error read-result)
            (conj entries {:ordinal @ordinal :start start :line line :column column
                           :read-error (:read-error read-result) :unread-from start})
            :else
            (let [end (char-offset starts n (sci/get-line-number rdr) (sci/get-column-number rdr))
                  source (str/trimr (subs text start end))
                  t0 (System/nanoTime)
                  outcome (try {:value (sci/eval-form ctx (:form read-result))}
                               (catch Throwable t {:error t}))
                  entry (merge {:ordinal @ordinal :source source
                                :start start :end (+ start (count source))
                                :line line :column column
                                :ns-before ns-before
                                :ns-after (sci/eval-form ctx '(ns-name *ns*))
                                :eval-ms (ms-since t0)}
                               outcome)]
              (vswap! ordinal inc)
              (recur (conj entries entry)))))))))

(defn read-evaluate
  "Stage 1. One source reader over the text; each form is read under SCI's
  live namespace table (aliases a previous form required resolve here), then
  evaluated exactly once, inside the batch's registration delta. A throw is
  the entry's :error; a reader failure ends reading and names the unread
  offset."
  [{:keys [ctx arm! delta] :as batch}]
  (let [ordinal (volatile! 0)
        stop (observe! ctx (fn [] @ordinal) (fn [v] (arm! batch v)))
        ;; Total: a throw outside any form (the delta, the reader setup)
        ;; becomes an entry, so the watch is always removed below.
        entries (try
                  (schema/call-with-registration-delta delta #(read-evaluate-loop batch ordinal))
                  (catch Throwable t [{:ordinal @ordinal :error t}]))
        effects (stop)]
    (assoc batch :entries entries :effects effects)))

        ;; against (the prelude declares it), so an edge to a definition made
        ;; after a nested namespace change resolves to the Var that ran.
        observed (into [] (comp (filter #(= :bind (:effect %))) (map :sym) (distinct)) effects)
        requests (mapv (fn [{:keys [source ns-before]}]
                         {:namespace-name ns-before
                          :form-source source
                          :seon.fn/namespace-row (namespace-entity ctx ns-before)
                          :seon.fn/declared observed})
                       forms)
        result (when (seq requests) (#'sfn/runtime-analysis-batch db requests))]
    (assoc batch :analysis result :analyzed-forms forms :requests requests)))

;;; ---------------------------------------------------------------------------
;;; Stage 3: join — every observed bind to at most one kondo definition.
;;; ---------------------------------------------------------------------------

(defn- synthetic-coordinates
  "Each analyzed form's first synthetic row and its input line/column: form
  i's first line starts at column 1 in the synthetic text."
  [{:keys [analysis analyzed-forms]}]
  (mapv (fn [[first-row _] {:keys [line column]}]
          {:first-row first-row :line line :column column})
        (:seon.fn/source-spans analysis) analyzed-forms))

(defn- to-synthetic
  "An input (line, column) inside form i as a synthetic (row, col)."
  [{:keys [first-row line column]} [l c]]
  [(+ first-row (- l line)) (if (= l line) (+ 1 (- c column)) c)])

(defn- contains-pos? [{row ::analyzer/row col ::analyzer/col end-row ::analyzer/end-row end-col ::analyzer/end-col} [r c]]
  (and row end-row
       (or (< row r) (and (= row r) (<= col c)))
       (or (< r end-row) (and (= r end-row) (< c end-col)))))

(defn join
  "Stage 3. For each Var's final bind: the kondo definitions of its name that
  either start at the bind's origin (the def form that ran) or lie inside the
  call form at the origin and are defined by that call's own operator (a
  defprotocol's methods, a defrecord's constructors). Exactly one is a match;
  none is :unanalyzed (a form kondo does not expand, or a runtime intern/eval:
  no static facts are asserted); several is :ambiguous. The namespace is
  SCI's; a kondo namespace that differs is reported, never substituted."
  [{:keys [analysis effects analyzed-forms] :as batch}]
  (let [coords (synthetic-coordinates batch)
        a (:seon.fn/analysis analysis)
        defs (group-by (comp str ::analyzer/name) (::analyzer/var-definitions a))
        usages-at (group-by (juxt ::analyzer/row ::analyzer/col) (::analyzer/var-usages a))
        form-index (into {} (map-indexed (fn [i f] [(:ordinal f) i])) analyzed-forms)
        final-binds (vals (reduce (fn [m e] (if (= :bind (:effect e)) (assoc m (:var e) e) m)) {} effects))
        joined
        (mapv
         (fn [{:keys [sym origin ordinal] :as bind}]
           (let [i (form-index ordinal)
                 {:keys [line column]} origin]
             (if-not (and i line)
               (assoc bind :join :unanalyzed :reason (if line :no-analyzed-form :runtime-origin))
               (let [pos (to-synthetic (coords i) [line column])
                     same-name (get defs (name sym))
                     at-origin (filter #(= pos [(::analyzer/row %) (::analyzer/col %)]) same-name)
                     call (first (get usages-at pos))
                     operator (when call (symbol (str (::analyzer/to call)) (str (::analyzer/name call))))
                     inside (when call
                              (filter #(and (contains-pos? call [(::analyzer/row %) (::analyzer/col %)])
                                            (= operator (::analyzer/defined-by %)))
                                      same-name))
                     candidates (distinct (concat at-origin inside))]
                 (case (count candidates)
                   0 (assoc bind :join :unanalyzed :reason :no-definition-at-origin :operator operator)
                   1 (let [d (first candidates)]
                       (cond-> (assoc bind :join :matched :kondo d)
                         (not= (namespace sym) (str (::analyzer/ns d)))
                         (assoc :kondo-ns-differs (::analyzer/ns d))))
                   (assoc bind :join :ambiguous :candidates (count candidates)))))))
         final-binds)]
    (assoc batch :joined joined)))

;;; ---------------------------------------------------------------------------
;;; Stage 4: derive — program rows from the same analysis, no second kondo run.
;;; ---------------------------------------------------------------------------

(defn- batch-rows
  "seon.fn/source-rows over the batch's one analysis (requests instead of a
  single form). Answers rows keyed by [form-index utf8-offset-in-form name]."
  [{:keys [db analysis requests]}]
  (let [{a :seon.fn/analysis text :seon.fn/source spans :seon.fn/source-spans
         function-entities :seon.fn/function-rows} analysis
        context (#'sfn/text-context text)
        byte-starts (:seon.fn/byte-line-starts context)
        functions (into (#'sfn/first-party-function-symbols a) (map :seon.fn/sym) function-entities)
        submitted (#'sfn/source-analysis a (ffirst spans) (second (peek spans)))
        projection (db/carried-projection db)
        entities (#'sfn/analysis-entities-by-file
                  submitted functions {"<stdin>" context}
                  (#'sfn/program-targets db (#'sfn/population-targets projection (#'sfn/invoked-attributes submitted)) functions)
                  projection)
        form-starts (mapv (fn [[first-row _]] (nth byte-starts (dec first-row))) spans)
        form-of (fn [offset] (last (keep-indexed (fn [i s] (when (<= s offset) i)) form-starts)))
        entity-shapes (program/shapes-in projection)]
    (into {}
          (keep (fn [entity]
                  (when (and (or (:seon.fn/sym entity) (:seon.test/sym entity)) (:seon.fn/form-span entity))
                    (let [[s _] (:seon.fn/form-span entity)
                          i (form-of s)
                          ns-row (:seon.fn/namespace-row (nth requests i))
                          row (program/declaration-row
                               projection
                               (program/canonical-row entity-shapes (dissoc entity :seon.fn/file :seon.fn/form-span))
                               :all :agent)]
                      [[i (- s (form-starts i)) (name (or (:seon.fn/sym entity) (:seon.test/sym entity)))]
                       (assoc row :seon.program/definition-digest
                              (db/definition-digest-of projection row ns-row))]))))
          (get entities "<stdin>"))))

(defn- origin-byte-offset
  "UTF-8 offset, within form i's source, of the bind origin."
  [{:keys [source line column]} [l c]]
  (let [ls (line-starts source)
        k (- l line)
        char-off (+ (get ls k) (- c (if (zero? k) column 1)))]
    (utf8-length (subs source 0 char-off))))

(defn- schema-rows
  "One canonical row per key the delta changed: registered keys upsert,
  removed keys delete. `:stored?` says whether an entity map lists the key."
  [{:keys [delta] :as batch}]
  (let [changed (sort (schema/changed-keys delta))]
    (when (seq changed)
      (let [candidate (candidate-projection batch)
            forms (:seon.schema.projection/forms candidate)
            stored (set (schema.datahike/database-attributes-in candidate))]
        (mapv (fn [k]
                (if-let [form (schema/registration-delta-form delta k)]
                  {:row (program/declaration-row
                         candidate
                         (program/with-contract-facts
                          {:seon.program/row (accretion/schema-row
                                              forms {:seon.schema/key k :seon.schema/form (pr-str form)
                                                     :seon.schema.admission/source :agent})
                           :seon.program/compile-options (:seon.schema.projection/compile-options candidate)
                           :seon.program/predicate-functions (schema/predicate-functions-in candidate)
                           :seon.program/schema-keys (set (keys forms))
                           :seon.program/schema-forms forms})
                         :all :agent)
                   :stored? (contains? stored k)}
                  {:row {:seon.program/delete-identities [[:seon.schema/key k]]}}))
              changed)))))

(defn derive-rows
  "Stage 4. Rows for matched binds whose root is a function or test, with
  the runtime contract from the Var (SCI owns the evaluated metadata), and
  the schema rows of the delta."
  [{:keys [joined analyzed-forms ctx analysis db] :as batch}]
  (let [rows-by-origin (if analysis (batch-rows batch) {})
        form-index (into {} (map-indexed (fn [i f] [(:ordinal f) i])) analyzed-forms)
        ;; A definition kondo analyzed in another namespace than the one SCI
        ;; defined it in (a namespace change inside its own top-level form):
        ;; its exact span, analyzed again as its own request in SCI's
        ;; namespace. Keyed by symbol; never substituted by name elsewhere.
        synthetic (:seon.fn/source analysis)
        text-starts (when synthetic (line-starts synthetic))
        span-of (fn [{r ::analyzer/row c ::analyzer/col er ::analyzer/end-row ec ::analyzer/end-col}]
                  (subs synthetic (char-offset text-starts (count synthetic) r c)
                        (char-offset text-starts (count synthetic) er ec)))
        moved (filterv :kondo-ns-differs joined)
        reanalyzed
        (when (seq moved)
          (let [requests (mapv (fn [{:keys [sym kondo]}]
                                 (let [n (symbol (namespace sym))]
                                   {:namespace-name n :form-source (span-of kondo)
                                    :seon.fn/namespace-row (namespace-entity ctx n)
                                    :seon.fn/declared (mapv :sym joined)}))
                               moved)
                again {:db db :requests requests
                       :analysis (#'sfn/runtime-analysis-batch db requests)}]
            (into {} (map (fn [[[i _ nm] row]] [(symbol (str (:namespace-name (nth requests i))) nm) row]))
                  (batch-rows again))))
        rows (vec
              (keep (fn [{:keys [var sym origin ordinal join kondo-ns-differs]}]
                      (when (= :matched join)
                        (let [i (form-index ordinal)
                              off (origin-byte-offset (nth analyzed-forms i) [(:line origin) (:column origin)])
                              row (if kondo-ns-differs
                                    (get reanalyzed sym)
                                    (get rows-by-origin [i off (name sym)]))
                              contract (:malli/schema (meta var))]
                          ;; The root SCI bound decides the kind: a function
                          ;; (or a test Var) is a program row; any other root
                          ;; (data, atom, MultiFn, protocol) is a private def.
                          (when (and row (or (fn? @var) (:test (meta var))))
                            (cond-> row
                              contract (assoc :seon.fn/spec (pr-str contract)))))))
                    joined))
        row-syms (into #{} (keep #(or (:seon.fn/sym %) (:seon.test/sym %))) rows)
        private (vec (for [{:keys [sym join]} joined
                           :when (not (row-syms sym))]
                       {:sym sym :join join}))
        schemas (schema-rows batch)]
    (assoc batch :rows rows :private private :schema-rows (mapv :row schemas)
           :schema-notes (into [] (keep (fn [{:keys [row stored?]}]
                                          (when (and (:seon.schema/key row) (not stored?))
                                            {:seon.schema/key (:seon.schema/key row) :seon.schema/stored? false})))
                               schemas))))

;;; ---------------------------------------------------------------------------
;;; Stage 5: gate — entry policy as diagnostics beside the values.
;;; ---------------------------------------------------------------------------

(defn gate
  "Stage 5. Entry policy: a function row needs its contract. A refused row is
  a diagnostic; its value stays in its entry."
  [{:keys [rows] :as batch}]
  (let [missing (vec (for [r rows :when (and (:seon.fn/sym r) (not (:seon.fn/spec r))
                                             (not (:seon.fn/macro? r)) (not (:seon.fn/host-bound? r)))]
                       {:seon.error/message (str (:seon.fn/sym r) " declares no :malli/schema")
                        :seon.error/member :seon.fn/spec
                        :seon.fn/sym (:seon.fn/sym r)}))
        refused (set (map :seon.fn/sym missing))]
    (-> batch
        (assoc :admitted (vec (remove #(refused (:seon.fn/sym %)) rows)))
        (update :diagnostics (fnil into []) missing))))

;;; ---------------------------------------------------------------------------
;;; Stage 6: settle — ONE transaction for the batch.
;;; ---------------------------------------------------------------------------

(defn- schema-tx
  "The batch's schema change as one transaction part: every changed key's
  attribute declarations (seon.turn/schema-attribute-change-tx over the whole
  changed set) plus its entity upsert or retraction."
  [{:keys [db delta schema-rows] :as batch}]
  (if (empty? schema-rows)
    []
    (let [current (db/carried-projection db)
          candidate (candidate-projection batch)
          attribute-tx (#'turn/schema-attribute-change-tx db current candidate (schema/changed-keys delta))]
      (into (vec attribute-tx)
            (mapcat (fn [row]
                      (if-let [[[_ k]] (:seon.program/delete-identities row)]
                        (when-let [id (:db/id (db/pull db [:db/id] [:seon.schema/key k]))]
                          [[:db/retractEntity id]])
                        (let [k (:seon.schema/key row)
                              existing (db/pull db '[*] [:seon.schema/key k])]
                          (if (:db/id existing)
                            (program/exact-replacement-tx existing row)
                            [(assoc row :db/id (str "schema:" k))])))))
            schema-rows))))

(defn settle
  "Stage 6. One transaction: namespace upserts for every namespace an entry
  started or ended in, the schema part, and every admitted row's writer data
  (seon.turn/row-tx) computed against the basis with the schema part applied,
  so a contract may name a schema the same batch registered. Applied once
  (seon.db/with: the writer's checks and final-report validator, never
  committed). A refusal is data on :commit."
  [{:keys [db admitted entries] :as batch}]
  (let [row-tx #'turn/row-tx
        ns-names (into (sorted-set) (comp (mapcat (juxt :ns-before :ns-after)) (remove nil?)) entries)
        ns-tx (into [] (keep (fn [n] (when-not (:db/id (db/pull db [:db/id] [:seon.ns/name n]))
                                       {:db/id (str "namespace:" n) :seon.ns/name n})))
                    ns-names)
        t0 (System/nanoTime)
        schema-part (schema-tx batch)
        basis (if (seq schema-part) (db/with db (into ns-tx schema-part)) db)
        fn-part (if (:seon.error/at basis)
                  []
                  (into [] (mapcat #(row-tx basis {:seon.program/row %} %)) admitted))
        tx (-> ns-tx (into schema-part) (into fn-part))
        tx-build-ms (ms-since t0)
        t1 (System/nanoTime)
        after (cond (:seon.error/at basis) basis
                    (seq tx) (db/with db tx)
                    :else db)]
    (assoc batch :tx-count (count tx) :tx-build-ms tx-build-ms :tx-apply-ms (ms-since t1)
           :after after
           :commit (if (:seon.error/at after)
                     {:refused (select-keys after [:seon.error/message :seon.error/member])}
                     {:applied (not (identical? after db))}))))

;;; ---------------------------------------------------------------------------
;;; Stage 7: reply — total: every entry keeps its value.
;;; ---------------------------------------------------------------------------

(defn reply
  "Stage 7. One map: each entry's value (printed here only for the probe),
  the joins, the schema notes, the diagnostics and the commit."
  [{:keys [entries diagnostics commit joined schema-notes] :as batch}]
  (assoc batch :reply
         {:values (mapv (fn [e] (cond (contains? e :value) (binding [*print-length* 8 *print-level* 3]
                                                              (pr-str (:value e)))
                                      (:error e) (str "ERR " (ex-message (:error e)))
                                      :else (str "READ " (:read-error e))))
                        entries)
          :joins (mapv (fn [j] [(:sym j) (:join j) (or (:reason j) (:kondo-ns-differs j))]) joined)
          :schema-notes schema-notes
          :private (mapv :sym (:private batch))
          :diagnostics (into (mapv :seon.error/message diagnostics)
                             (keep :arm-error) (:effects batch))
          :commit commit}))

;;; ---------------------------------------------------------------------------
;;; The one function.
;;; ---------------------------------------------------------------------------

(defn arm-contract!
  "Arming stage value: Seon's own contract installer on the Var's root,
  under the batch's candidate projection (a schema the batch registered
  earlier is visible to the contract)."
  [{:keys [ctx db delta] :as batch} v]
  (when-let [contract (:malli/schema (meta v))]
    (let [projection (if (seq (schema/changed-keys delta)) (candidate-projection batch) (db/carried-projection db))]
      (#'eval/install-function-contract!
       ctx {:seon.fn/sym (var-symbol v) :seon.fn/spec (pr-str contract)}
       projection db))
    (.getRawRoot ^sci.lang.Var v)))

(defn run
  "The one pipeline: input map {:db :text :start-ns :ctx :arm!} to the batch."
  [{:keys [db text start-ns] :or {start-ns 'user} :as input}]
  (let [t0 (System/nanoTime)
        ctx (or (:ctx input) (eval/base-ctx db))
        batch {:ctx ctx :db db :text text :start-ns start-ns
               :delta (schema/begin-registration-delta (db/carried-projection db))
               :memo (volatile! [nil nil])
               :arm! (or (:arm! input) arm-contract!)}
        out (-> batch
                (stage :read-evaluate read-evaluate)
                (stage :analyze analyze)
                (stage :join join)
                (stage :derive derive-rows)
                (stage :gate gate)
                (stage :settle settle)
                (stage :reply reply))]
    (assoc out :total-ms (ms-since t0))))

(defn summary
  "The probe's compact view of one run."
  [r]
  {:reply (:reply r)
   :ms (into {:total (Math/round (double (:total-ms r)))
              :tx-build (some-> (:tx-build-ms r) double Math/round)
              :tx-apply (some-> (:tx-apply-ms r) double Math/round)}
             (map (fn [[k v]] [k (Math/round (double v))]) (:timings r)))
   :tx-count (:tx-count r)})

(comment
  (edn/read-string "{}"))

(ns entrants
  "Entrant stage values for the one pipeline (probe only)."
  (:require [clojure.string :as str]
            [sci.core :as sci]))

(defn jvm-read-evaluate
  "The JVM evaluator stage: Clojure's reader (read+string, live *ns*) and
  host eval, producing the same entries as the SCI stage. No custody, no
  observation: host Vars are not SCI mutations."
  [{:keys [text start-ns] :as batch}]
  (let [rdr (clojure.lang.LineNumberingPushbackReader. (java.io.StringReader. text))
        eof (Object.)]
    (binding [*ns* (create-ns start-ns)]
      (refer-clojure)
      (loop [entries [] ordinal 0]
        (let [line (.getLineNumber rdr)
              ns-before (ns-name *ns*)
              [form source] (try (read+string {:eof eof :read-cond :allow} rdr)
                                 (catch Throwable t [::read-error (ex-message t)]))]
          (cond
            (identical? eof form) (assoc batch :entries entries :effects [])
            (= ::read-error form) (assoc batch :entries (conj entries {:ordinal ordinal :read-error source}) :effects [])
            :else
            (let [outcome (try {:value (eval form)} (catch Throwable t {:error t}))]
              (recur (conj entries (merge {:ordinal ordinal :source (str/trim source) :line line
                                           :ns-before ns-before :ns-after (ns-name *ns*)}
                                          outcome))
                     (inc ordinal)))))))))

(defn jvm-batch
  "JVM entrant: same fold, JVM read/evaluate stage, reply stage; no settle."
  [text start-ns]
  (-> {:text text :start-ns start-ns}
      (#'pipeline/stage :read-evaluate jvm-read-evaluate)
      (#'pipeline/stage :reply pipeline/reply)))

(defn render-batch
  "Render entrant: the viewer's ctx forked (defs land in the fork and are
  discarded), a database VALUE as custody (no connection: no writer), the
  same read-evaluate and reply stages; derive/settle never run. A bind
  observed here is a diagnostic."
  [db viewer-ctx text]
  (let [fork (sci/fork viewer-ctx)
        out (-> {:ctx fork :db db :text text :start-ns 'user
                 :delta (seon.schema/begin-registration-delta (seon.db/carried-projection db))
                 :arm! (fn [_ _] nil)}
                (#'pipeline/stage :read-evaluate pipeline/read-evaluate)
                (#'pipeline/stage :reply pipeline/reply))]
    (update-in out [:reply :diagnostics] into
               (for [e (:effects out) :when (= :bind (:effect e))]
                 (str "a render form defined " (:sym e) "; renders are read-only, it was discarded")))))
