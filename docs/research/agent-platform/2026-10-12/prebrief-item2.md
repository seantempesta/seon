## 3. G8, reproduced from chain evidence

**What it means in data (VERIFIED from the schema and code).** An attempt is an entity keyed `:seon.task/assignment` (a uuid-ish key, `[handle number]`). Its end is `:seon.task.attempt/end` (enum, `:seon.wake/starts true`, `seon.task.attempt.edn` line 2). The agent writes its end on its **branch** (`seon.turn/end-task-call` and `end-task!`: "the end datom wakes db<->flow through the branch's route (`:seon.wake/starts`)"). Main does not hold it until db<->flow copies it there. G8 is: an assignment whose `:seon.task.attempt/end` is set on the branch, absent on main, with the branch's route silent, so `next-actions` never derives `:stop`, `:close`, `:merge`.

**Who should move it.** db<->flow (the proc `seon.cluster.agent/db<->flow`) on its next pass. The data is: `lifecycle-facts` reads `branch-end` on the branch when `main-end` is nil; `next-actions` then derives `:stop` (if started), `:merge-base`, `:merge`, `:close`. So the owner that should move the end is the wake from the branch to db<->flow's `:seon.flow/plan` in-port.

**The route, by symbol (VERIFIED).**
- `seon.cluster.agent/start-branch-flow!` calls `seon.cluster.wake/route!` with `:seon.cluster.wake/connection (:seon.db/connection execution)`, `:seon.flow/plan-channel (:seon.cluster.wake/channel cluster-handle)` and key `seon.cluster.agent/branch-route-key`. Then `start-flow!`. It is the only place a branch route is registered.
- `seon.cluster.wake/route!` listens on that connection (`d/listen`). On each report, an added datom whose attribute is in `starting-attributes` (`:seon.task.attempt/end` is one) does `(async/offer! plan-channel ::wake)`.
