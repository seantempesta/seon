## Non-trivial: need a design round before a lane

1. **#1 + #2: one landing basis.** Base = the last copied (or pushed) source commit recorded in main's provenance.
   The lifecycle (stop, release, delete) is derived by `plan` from roster plus end facts, and the marker filter is
   deleted. This is also C's core, so design it with C.
2. **#3: the copy as a writer function.** `squash-merge` runs inside the transaction on db-before, with conflict
   tasks as tx-data. This needs a tx-data form of `seon.task/create!`.
3. **#4: conflicts as root's merge decision.** The values and source commit become data, retention is derived
   from unresolved conflicts, and this reuses the merge-request owner rather than a `:held` prose task.
4. **#6: failure as an attempt fact.** The boundary records a failed start or landing as the attempt's `:error`
   end. The four catches are deleted, and `:attempt` plus `:start-flow` become one unit.
5. **#8 + #9: one starter, one intent table.** Delete `agents-to-start`, the `host!` start and the held exemption
   (decide what an outside agent's graph is). Implement R2 `:stopped`/`:cancelled`/`:paused` with
   acknowledgement, plus R3 `:seon.cluster/execution`.
6. **#5 + #12: the fork point (decided, F).** Lane `p4-branch-writes` implements it. Verify there that
   `fork-attempt!`'s fallback, the `sort/first`, `seed-attempt!` and `attempt-rows-tx` are deleted, not kept
   beside it.

Trivial now, about 15 min each: #11 (delete the rule), #7 (delete the inline branch, make the launcher required),
#9's `:stop` → `:seon.agent/finish? true`, and #2's "skip an empty copy". #10 and #13 are in flight in their owners'
lanes.
