- **Haiku: what paid off tonight and what did not.** Paid: the seven surveys as spot-checked evidence (sizes, counts, the law-break inventory, the ten slowest tests), the sentinel baseline and after-reset run, the pre-briefs used within the hour (M5–M7), chain-queue's method once its picks were checked. (3) The commit that moves a phase updates its plan table entry; plan.md is held by no build lane. (4) `bin/lane status` is the ledger of running work; the handoff note's RUNNING list is a view. (5) A static count is measured once per day and cited by commit; nobody re-measures a number a commit already carries. (6) Numbers in plan.md carry their commit; a number without one is stale. (7) A paid chain runs only after its blocker changed on default.

## 7. Questions for the owner

**Q1. Where does an automatic merge write files while default runs its committed archive?** (The one decision nothing on the merge path can finish without.)
- **A (recommended).** `:seon.config.fs/working-root` names the checkout; `seon.merge/publish!` commits only the merged paths with `git commit --only`, as `bin/lane commit` does, under a root-held `bin/lane` claim on those paths (a merge touching a lane-held path waits as due work until the claim is released: git's index, not a new hold). Guarantee: files, Datahike and git stay three distinguishable facts and a restart from HEAD loads what main holds. Cost: one dial, one claim rule, a day of Opus for M9 + M8a. Sacrifice: Seon's commits appear in the shared tree while lanes work.
- B. Merge into Datahike only; root writes files for all merged entities at each restart batch. Cost: nothing now. Sacrifice: main holds program entities no file holds for hours, which is the state fault 1 produces (AGENTS.md: default's program derives from files); a restart before the write-back loads a program that differs from main. Ruled out by the hybrid unless the owner wants it.
- C. A private index and request ref, or a worktree. Guarantee: no collision with lanes. Cost: a design round and the owner's worktree authorization; the first automatic merge a day later.
