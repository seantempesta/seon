# One happy path: reading and analysis (2026-09-24)

**What exists.** Six readers of Clojure text: `seon.sci.reader/read` over `sci/parse-next+string` (edamame), clj-kondo
(its rewrite-clj fork, 1 run + 3 re-parses per published file), rewrite-clj in `seon.edit`, `clojure.core/read` twice
(`src/seon/fn.clj:229`, `src/seon/fn/signature.cljc:17`) and `clojure.edn` over agent source (`src/seon/repl.clj:123`).
Four matchers decide "what is a definition": the reader (`reader.cljc:245,299,323`), `signature/declaration-parts`
(`signature.cljc:62`), `repl/def-note` (`repl.clj:118`), and clj-kondo `:var-definitions` (the program's analyzer).
**The one happy path.** clj-kondo is the one static analyzer (rows, edges, spans, ns clauses, metadata); SCI is the one
runtime authority (what an evaluation defined = the intern diff of a fork, already computed by `definition-row`
`src/seon/sci/eval.clj:417` over `turn-interns` `:363`); `seon.sci.reader` only splits text into forms with exact source.
Gaps in a dependency are fixed in our fork (clj-kondo, datahike, edamame are all `:local/root`, `deps.edn:16,55,57`).

So kondo-before-evaluation (the SCI lane's `gate-on-analysis-not-reader`) still misses macro-made definitions; the
owner-directed fork+diff (`language-requirements-2026-09-24.md:138`) sees all of them. Kondo stays the row authority.

Namespace clause `(:require clojure.set [clojure.string :as s :refer [join] :rename {join j}] [clojure.walk :refer :all]
[clojure.data :as-alias d]) (:import (java.io File))`:
- `seon.fn/namespace-context`: requires `#{clojure.string clojure.walk}`, so the bare `clojure.set` is **dropped**;
  a prefix list `[clojure [edn :as e]]` **throws** `IllegalArgumentException` (`fn.clj:257`).
- reader `namespace-info`: `clojure.set` kept; the prefix list gives requires `#{clojure}` and **no alias** (the
  `try … {}` at `reader.cljc:149-152` swallows it).
- kondo: `:namespace-usages` `[clojure.set nil] [clojure.string s] [clojure.walk nil] [clojure.data d]`; refers as
  `:var-usages :refer true`; imports as `:java-class-usages :import true`
  (`reference-code/clj-kondo/src/clj_kondo/impl/analyzer/namespace.clj:220-227,702,721`). It lacks the `:rename`
  local (reports `join`, not `j`) and an `:as-alias` flag.

Other measurements:
- SCI's returned source string equals the reader's recomputed `::source` on comments, `#_` and keywords, yet
  `read-events` discards it (`[form _]` `reader.cljc:566`).
- One parse of `fn.clj` (181 k chars): `parse-string-all` 9–10 ms, `sexpr` 5 ms, `seon.sci.reader/read` 33 ms,
  kondo run 205 ms. `clojure.edn` reads `(def q 'y)` silently and throws on `#(…)` and `::x`, which `def-note` swallows.
