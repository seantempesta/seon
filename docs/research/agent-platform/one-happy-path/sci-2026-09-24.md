# One happy path: SCI evaluation and agent contexts (2026-09-24)

**What exists.** Seven constructors make an SCI context: `build-base-ctx` (`src/seon/sci/eval.clj:204`),
`base-ctx`/`copy-base-ctx` (`:2490`, `:2476`), `cluster-ctx`/`cluster-ctx*` (`:2690`, `:2718`), `fork-cluster-ctx`
(`:2746`), `fork-for-turn` (`:2291`), `regenerate-agent-context!` (`:2228`), and `fork-candidate-ctx` (`:3636`). Five
paths put a definition into one: whole-program `acquire-program!` (`:1868`), per-row `install-row!` (`:937`),
post-settlement `install-evaluated-rows!` (`:1198`), the entry-gate `accept-candidate!` (`:3693`), and lazy
`kernel/ensure-function!` (`src/seon/sci/kernel.clj:162`).
**The one happy path** is the checkpoint model (`decoration-language-v0-2026-09-24.md` §4b):
- a base per loaded program, keyed by content;
- `sci/fork` (`reference-code/sci/src/sci/core.cljc:345`, 0.006 ms) for cluster, task and attempt;
- the rows that differ, interpreted once per `{sym digest}` set;
- proofs through the one `seon.test/run` on a throwaway fork.
The rest is a second path or rolled our own.

Extends `sci-context-efficiency-{opus,astra}-2026-09-24.md` (their costs are not repeated),
`fork-audit-others-2026-09-23.md` S4/S5, `cut-analysis-2026-09-23.md` B-e/B-f, and `three-entry-defects-2026-09-24.md`.
Claims below were rechecked at HEAD. Two of those claims have since changed:
- `turn-interns` already skips namespace maps `identical?` to the acquired program (`:364-401`, commit 88289e006).
- An evaluated contracted `defn` is armed at `evaluate` (`:3559-3565`), so entry-defect 4 is fixed at HEAD but not in the running JVM.

## Broken first

1. **The pre-evaluation contract gate reads the hand reader, so `(do (defn …))` bypasses it.**
   `evaluate` refuses a `defn` without `:malli/schema` only when `(:seon.fn/sym event)` is set (`eval.clj:3460`). Live
   (`seon.sci.reader/read`, installed JVM, reader unchanged at HEAD):
   - `(defn f [x] x)` → `#:seon.fn{:sym scratch.x/f}`;
   - `(do (defn f [x] x))`, `(let [] (defn …))` and `(intern *ns* 'f …)` → `{}`.

   The gate therefore sees only a top-level `defn`.
2. **Direct host Vars in SCI (probe P1, disposable local `sci/init`, scratch JVM Var).** This is the option both
   efficiency studies left open.
   - Installing `#'scratch.happy-sci/f` directly: a JVM `alter-var-root` is visible to an analysed SCI caller (`1 → 2`), and
     no fork write reaches the JVM root.
   - `sci/bind-root!` on it **throws** (`No implementation of :toSymbol of protocol IVar for clojure.lang.Var`).
   - `sci/add-namespace!` with a new SCI Var overrides `h/f` in the fork only (`[5 4]` fork, `[4 4]` base), while the already-analysed
     caller keeps the host Var. Callers of an override must still be re-interpreted, as they are today.
   - The `copy-var*` copy used today did **not** see a later reload (`2` after root `4`). This is why adoption must rebuild the whole base.

## Totals, slices, dependency gaps

**Deletable in this area: about 900 lines**, of which about 110 are UNVERIFIED (the lazy install) and about 70 sit in turn.clj.
The file contributions are eval.clj about 760, kernel.clj about 95, turn.clj about 70. None of these deletions needs new machinery: the replacements
are `sci/fork`, `sci/resolve`, `sci/add-namespace!`, `seon.test/run`, `reload-order`, commit ids and definition digests.

**The three highest-value slices:**
1. **`base-keyed-by-content` together with `install-coverage-is-the-key`** (≈235). This removes rebuilds per revision.
   Prerequisite: fn.clj's declared-edge fix (opus slice 1) so a miss costs about 150 ms, not 916 ms. Design review first.
2. **`entry-gate-is-seon-test-run`** (≈270). This is one runner. Its prerequisite is test.runner removing the 1.6 s history scan and
   0.6 s blob publication, so a gate member costs about 130 ms, not 3.3 s.
3. **`checkpoints-are-forks`** (≈150). This is §4b made literal and needs the owner's ruling on scratch.
   `gate-on-analysis-not-reader` is small and closes a live contract bypass, so it goes first regardless.

**What the dependency genuinely lacks. Fix these in our SCI fork, not beside it:**
- `sci/bind-root!` on a host `clojure.lang.Var` throws (probe P1). Fix: fork copy-on-write that replaces the namespace entry with an SCI Var
  of the fork's generation, which is what `add-namespace!` does by hand. Place it next to 72150fd4 (`impl/utils.cljc:362-379`).
- There is no public alias/refer installer upstream. The fork's `namespace-bindings`/`install-namespace-bindings!` (2217449d) stay; they are
  an upstream PR candidate (fork-audit).
- Outside SCI, Datahike's join-bound-attribute planner gap drives the cost of every miss (opus §2.1). That goes to the datahike fork, not a caller rewrite.
