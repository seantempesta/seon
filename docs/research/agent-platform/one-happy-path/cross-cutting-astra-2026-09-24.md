# One happy path across the system

Publication, interpretation, tests, rendering and fault delivery already share database facts, but independently select their meaning, identity and policy. Keep the existing producer of each value, pass its answer to consumers, and delete their competing derivations; do not introduce a general cache, registry or service layer.

**Broken first:** a failed repeated fault write can bypass panic (P2); different declaration populations collide in the key of an SCI cache (P7); printed-content identities depend on print bindings (P1); a test reach leaf omits fixture metadata that the declaration digest includes (P3). These are measured differences, not claims that a complete user workflow was tested.
