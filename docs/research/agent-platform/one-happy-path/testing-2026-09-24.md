# Testing: one happy path (2026-09-24)

**What exists.** One pipeline already runs a test the way it runs an agent: `seon.test/run`
(`src/seon/test.clj:1621`) → `member-result` (`:1447`): `acquire-context!` isolated branch + SCI fork +
custody → `bounded-result` (`:133`) → `runner/run-var!` (`test/runner.clj:392`), which binds
`clojure.test/report` and calls `clojure.test/test-vars` (`reference-code/clojure/src/clj/clojure/test.clj:723`)
→ `commit-results!` → `release-context!`. `my.test`, `bin/test-check`, `bin/test --platform`, the save gate,
the merge gate and `plan/run-issue-tests!` all enter it. **That pipeline is the owner to keep.** Everything
below is a second isolation, a second drift detector, a second staleness decision, a second runner or
a copy of a dependency function around it.

**Principal approach.** Delete the second mechanisms; route every run through `seon.test/run`; where a
dependency does the job (Malli's function checker, Datahike's attribute revisions, `seon.id/sha-256`), call it,
and add the missing option in our fork.
