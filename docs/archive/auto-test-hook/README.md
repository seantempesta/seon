# Example Feature PRD Structure

This is an example showing how the PRD system works. The `_example-feature` directory demonstrates the structure without cluttering the actual PRDs.

**Directory contents:**
- `prd.md` - Main specification with minimal content (shows structure)
- `decisions.md` - Example architectural decision
- `notes.md` - Example implementation notes
- `research/` - Example research documents

**To create a real feature:**
1. Copy this structure: `cp -r docs/prds/_example-feature docs/prds/your-feature-name`
2. Update content in each file
3. Delete this README.md
4. Start working!

See `../readme.md` for full documentation.
