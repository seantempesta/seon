# Historical Hyperlith pattern survey

> Historical dependency research only. Its atom watches, `refresh-all!`, full
> view pushes, and application recipes are not Seon APIs. Use
> [[datastar-quick-reference]].

The 2025-12-02 survey mined Hyperlith for a simple server-driven UI shape. The
copied framework code and Seon recommendations were deleted after fresh Seon
adopted database `listen!`, Flow rendering, stable block identity, equality
suppression, and per-tab element morphs instead. Git is the archive.

The dependency remains available under `reference-code/hyperlith/` for source
archaeology. The maintained implementation is `src/seon/render/web.clj`.
