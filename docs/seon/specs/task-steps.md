# Task steps

Superseded by [TASK-CHAIN](../schedule/cards/TASK-CHAIN.md). Steps, `needs` and `children` are deleted (§1, §6): a chain
is tasks linked by `:seon.task/next`, worked one after another on one branch (§2). The plan-as-steps verbs this spec
proposed (`my.task/plan!`, `step!`) are not installed.
