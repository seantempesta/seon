# Agent Observatory

A live view of all agent activity -- running, completed, and their full conversation logs. The observatory makes agent work visible, enabling the human operator to monitor progress and intervene when needed.

## What Exists

- `/agents` page shows running and completed agents
- Full conversation rendering with tool calls and results
- SSE-driven live updates as agents work
- Detail views per agent with complete conversation history
