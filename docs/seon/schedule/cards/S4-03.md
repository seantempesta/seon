# S4-03 History is the agent's own exchanges

Ledger row S4-03 (group A/D). Spec: agent-loop.md §3.4 "History": an exchange is a pass's call row and its
evaluations with source and shown text; only call rows carrying a model attempt reach the model; no origin tag.
Lane: Sonnet. Prefer deletion: the selection code this replaces is deleted by S4-07b2/b3; do not tune it.

## Files
`src/seon/render/transcript.clj`, `src/seon/eval.clj`, `src/seon/repl.clj` (read only: `value-text`),
`resources/seon/schemas/seon.render.transcript.edn` (create if absent; otherwise add keys there),
`test/seon/render/transcript_run_test.clj`.

## Functions
- ADD `seon.eval/exchanges`
  `{:malli/schema [:=> [:cat :seon.db/database-value :seon.agent/id :seon.task/assignment] [:vector :seon.render.transcript/exchange]]}`
  `[database agent-id assignment]`. Reads `(of-agent database agent-id history-selector)` (S4-01's ordinal order,
  `src/seon/eval.clj:17`), groups by `:seon.cluster.eval/run`, keeps runs whose call row has
  `:seon.turn/assignment` `=` `assignment` and a non-empty `:seon.turn/attempts` (S4-02a), in first-ordinal order.
- ADD `seon.render.transcript/exchange-text`
  `{:malli/schema [:=> [:cat :seon.render.transcript/exchange] :string]}`: the form source as sent, then its shown
  text, per evaluation, joined with newlines; the shown text through `seon.repl/value-text`
  (`src/seon/repl.clj:164`), the one reader SR-F later teaches blobs. Never re-renders a value.
- No change to `render-run-ai` (`src/seon/render/transcript.clj:698`) in this card.

## Schema
```edn
:seon.render.transcript/exchange
[:map [:seon.turn/id :seon.turn/id]
      [:seon.turn/reply {:optional true} :seon.turn/reply]
      [:seon.render.transcript/evaluations
       [:vector [:map [:seon.cluster.eval/id :seon.cluster.eval/id]
                      [:seon.cluster.eval/source {:optional true} :seon.cluster.eval/source]
                      [:seon.eval/shown {:optional true} :seon.eval/shown]]]]]
```

## Data
```edn
{:seon.turn/id "t-9" :seon.render.transcript/evaluations
 [{:seon.cluster.eval/id "e1" :seon.cluster.eval/source "(+ 1 2)" :seon.eval/shown "3"}]}
```

## Proof
`seon.render.transcript-run-test/reacquired-history-is-the-finished-exchange` (new). Two fixture-model passes and one
`seon.mcp/call` outside pass for one assigned agent; then `(seon.eval/exchanges db agent-id key)`: two exchanges
(the outside pass has no attempt), in pass order, each evaluation's `:seon.eval/shown` equal to what that pass's
reply showed. Also an error form, a form with `:out` output and a diagnostic: the stored shown text is what the reply
printed (design-notes §6 asks for errors, output and diagnostics).

composed cold at 200 × 2 KB, design-notes §6). It runs once per proc start or new assignment (S4-04), never per call.
