# CS-01c1: The block shows the Seon names a task references

Depends on: CS-01a. Group D (serial with CS-01b: same files). Model: Sonnet.

## Functions

```clojure
(defn- referenced-names
  "The names a task references: its must-reads and the qualified symbols and keywords backticked in its intent, in first-seen order."
  {:malli/schema [:=> [:cat :seon.context/task] [:vector [:or :qualified-symbol :qualified-keyword]]]}
  [task] ...)
```

Reading the intent: every backticked span is read with `edamame.core/parse-string` (edamame, AGENTS.md "reading
Clojure text"; no regex on code); the span's boundaries are found by `clojure.string/split` on the backtick
character, taking the odd-indexed pieces. A piece that does not parse, or parses to anything but a qualified symbol
or keyword, is skipped (prose). Must-reads (`:seon.task/must-read`, a set) come first, sorted; then intent names not
already present. (`:seon.task/must-read` is already in CS-01a's `task-selector`.)

```clojure
(defn- must-read
  "One referenced name resolved to its current definition on `database`, or a problem."
  {:malli/schema [:=> [:cat :seon.db/database-value [:or :qualified-symbol :qualified-keyword]]
                  [:or :seon.context/must-read :seon.context/name-problem :seon.error/value]]}
  [database name] ...)
```

- Symbol: `(db/pull database [:seon.fn/sym :seon.fn/arglists :seon.fn/spec :seon.fn/doc] [:seon.fn/sym name])`
  (attribute names verified at the REPL on default: a function entity carries `:seon.fn/arglists`, `:seon.fn/spec`,
  `:seon.fn/doc`). Found → `{:seon.context/name name :arglists … :seon.fn/spec … :doc (first line)
  :seon.render/operations [(list 'doc name) (list 'clojure.repl/source name)]}`; the first docstring line comes from
  `seon.sci.eval/docstring-parts` (`sci/eval.clj:1891`). Not a function: try `[:seon.test/sym name]` (a test: name
  and the two operations) and `[:seon.ns/name name]` when `name` has no namespace part — otherwise a problem.
- Keyword: the same read `seon.sci.eval/schema-documentation` makes (`sci/eval.clj:2070`, private): make it public
  (drop the `-`, keep its contract) and call `(seon.sci.eval/schema-documentation database k k)`; its `:form` becomes
  `:seon.context/schema-form`, operation `(doc k)`. Its unavailable error means unresolved. Add `src/seon/sci/eval.clj`
  to the claim for this one-character change (group C: ask root if another lane holds it).
- Nothing → `{:seon.context/name name :seon.context/problem :unresolved}`.
CS-01c2 adds the library fallback to this function; do not add it here.

Change `current-state`: when the held task has names, `(assoc :seon.context/must-reads (mapv #(must-read database %) names))`;
an element with `:seon.error/at` is returned whole. Unresolved names stay in the vector (the spec: "a problem on the
task").

`my.turn/usage-form`'s contract, `src/my/turn.clj:31`).

## Proofs

`seon.context-test/the-block-resolves-the-names-a-task-references`: create task `tq.cs/names` with intent
``"Use `seon.task/home` and `:seon.task/intent`."`` and `:seon.task/must-read #{seon.task/agent-task}`; assign; read the
block through `seon.mcp/call`. Assert `(mapv :seon.context/name must-reads)` =
`['seon.task/agent-task 'seon.task/home :seon.task/intent]` and the `seon.task/home` entry's operations contain
`'(doc seon.task/home)`.

`seon.context-test/a-task-naming-a-missing-symbol-shows-a-problem`: intent ``"Fix `tq.cs/missing`."``; assert the entry
is `{:seon.context/name 'tq.cs/missing :seon.context/problem :unresolved}`.
