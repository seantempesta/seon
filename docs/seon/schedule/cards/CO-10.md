# CO-10 A query aligns its inputs once

Pattern P2 (Opus I7/F5). Lane: Sonnet. Blocked on owner Q1 (merged.md §4).

## What exists
`seon.db/q`'s contract guard `query-call-valid?` normalizes the query and computes `query-input-position`; the
body's `aligned-query-arguments` computes the same and already returns `query-input-shape-error` as data. Guard
2.9 µs of a one-clause `q`'s 47.7 µs armed (Datahike `d/q` 2.2 µs).

## Change (Q1 recommended)
Delete the guard (and `query-guard-message`); the input and output schemas stay, the output union keeps the
refusal, the body is the one alignment.

## Proof
Existing malformed-query refusal tests stay green (the refusal type and message unchanged);
`seon.db-overhead-test/query-preparation-has-bounded-armed-work` asserts `(calls-of m 'seon.db/query-input-position)` 1 per `q`.

## Cost
Expected: one alignment per `q`. Parent two.
