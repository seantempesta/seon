# CS-01c3: The block shows a reference-code path

Depends on: CS-01c2. Group D. Model: Sonnet.

## Files

- `src/seon/context.clj`
- `src/seon/test/cache.clj`
- `resources/seon/schemas/seon.context.edn`
- `test/seon/context_test.clj`

## What is true at HEAD

- `:seon.task/must-read` holds symbols only (`seon.task.edn:11`, `:seon.program/edge-symbol`), so a path reaches the
  block only as a backticked span in the intent: `` `reference-code/malli/README.md` ``.
- The loaded JVM's source directory (`seon.fs/source-directory`, `src/seon/fs.clj:218`; on default
  `data/source/<commit>`) holds `dependency-pins.txt`, `git ls-files --stage` lines
  (`160000 43c6dca8… 0\treference-code/malli`). `seon.test.cache/gitlink-digests` (`test/cache.clj:178`) already
  parses those lines, then hashes each pin.
- Each pin is extracted once at `data/source/pins/reference-code-<project>/<rev>/` (`script/seon/operator.clj:868`);
  `…/reference-code-malli/43c6dca8…/README.md` exists.

## Functions

Split `seon.test.cache/gitlink-digests` (one parse, two uses):

```clojure
(defn gitlink-pins
  "Each submodule path's pinned 40-character commit id; snapshot pins take precedence over the live index."
  {:malli/schema [:=> [:cat :string] [:map-of :string [:string {:min 40 :max 40}]]]}
  [root] ...)   ; the current body of gitlink-digests up to the pair, answering [path rev]
(defn gitlink-digests ...)   ; unchanged contract: (update-vals (gitlink-pins root) #(hasch/hash->str (hasch/sha256 (.getBytes ^String % "UTF-8"))))
```

In `seon.context`:

```clojure
(defn- reference-path
  "A `reference-code/<project>/…` path at the loaded JVM's pin, or a problem."
  {:malli/schema [:=> [:cat :string] [:or :seon.context/must-read :seon.context/name-problem]]}
  [path] ...)
```

Body: split `path` on `/` (`clojure.string/split`); project = second element, rest = the elements after it joined
by `/`. `rev` = `(get (seon.test.cache/gitlink-pins (seon.fs/source-directory)) (str "reference-code/" project))`.
File = `(io/file (.getParentFile (io/file (seon.fs/source-directory))) "pins" (str "reference-code-" project) rev rest)`.
Exists → `{:seon.context/path path :seon.context/pin {:seon.context/project project :seon.context/revision rev}
:seon.render/operations [(list 'slurp (.getCanonicalPath file))]}`; else
`{:seon.context/path path :seon.context/problem :unresolved}`.

Change `referenced-names` (CS-01c1): a backticked span whose text starts with `"reference-code/"`
(`clojure.string/starts-with?`) is kept as a string, before edamame reads anything. Change `must-read`: a string
name goes to `reference-path`.

## Schemas

Add two map schemas and widen the vector (no optional-name juggling):

```clojure
:path [:string {:min 16}]
:path-read [:map [:seon.context/path :seon.context/path] [:seon.context/pin :seon.context/pin]
            [:seon.render/operations [:vector :seon.render/read-form]]]
:path-problem [:map [:seon.context/path :seon.context/path] [:seon.context/problem [:enum :unresolved]]]
:must-reads [:vector [:or :seon.context/must-read :seon.context/name-problem
                      :seon.context/path-read :seon.context/path-problem]]
```

## Proof

`seon.context-test/a-reference-code-path-shows-its-revision-and-a-read-form`: intent
``"Read `reference-code/malli/README.md` first."``; assigned; block through `seon.mcp/call`. Assert the entry's
`:seon.context/path` is the string, its revision is 40 characters, and its operation is a `slurp` form whose argument
names an existing file. A second task naming `reference-code/malli/NO-SUCH.md` shows `:seon.context/problem :unresolved`.
(In a throwaway check JVM the source directory is the candidate archive, which carries `dependency-pins.txt`.)

`--test seon.context-test --test seon.test.gitlink-digest-test` (`test/seon/test/gitlink_digest_test.clj`, the only test naming `gitlink-digests`;
`script/seon/operator.clj` has its own copy under Babashka and is not touched).
