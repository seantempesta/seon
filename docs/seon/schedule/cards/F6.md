# F6: Tasks answered with data finish from their proofs

**Blocked on Q-A** through A1. Depends on A1 (F1 landed). Group E. Model: Sonnet.

## Decided

- No kind, no `:question` member (OD-Q9, no-kinds ruling). A question task is one whose proof calls `my.task/answer`.
- Files: `src/my/task.clj`, `resources/seon/schemas/seon.test.member.edn`, `src/seon/test.clj`,
  `resources/seon/schemas/seon.task.edn` (`my.task`'s request schemas live there; there is no `my.task.edn`),
  `test/seon/competency_test.clj`.
- `my.task/answer` `[:=> [:cat [:map [:seon.test.run/tested-branch :seon.test.run/tested-branch]]] [:or <A1's answer
  schema> :seon.error/value]]`: reads `:seon.agent/answer` of the agent whose branch is the tested branch (outside a
  test member the input is missing and the call refuses by name) and records the answer digest on the member as
  `:seon.test.member/answer :seon.blob/digest` (new attribute in `seon.test.member.edn`, optional in `:member`).
  `:seon.test.run/tested-branch` is installed (`seon.test.run.edn:29`, optional on the run at `:125`); a member world
  must supply it as a world member for the supplier to fill it — confirm with one `eval_clj` inside a test body
  before writing; if the member world does not carry it, the card returns to root.
- `seon.test/verified?` (`test.clj:1573`, 2-arity): green additionally requires, when the result carries
  `:seon.test.member/answer`, that it equals the tested branch's current `:seon.agent/answer`.
- Proofs: `seon.competency-test/an-answer-without-code-runs-its-proof`, `…/a-changed-answer-invalidates-green`,
  `…/a-changed-answer-source-invalidates-green` (ledger row).
