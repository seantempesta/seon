# F6: Tasks answered with data finish from their proofs

**Q-A answered** (answers are specced data, A1). Depends on A1 (F1 landed). Group E. Model: Sonnet.

## Decided

- No kind, no `:question` member (OD-Q9, no-kinds ruling). A question task is one with `:seon.task/answer-schema`
  whose proof calls `my.task/answer`.
- Files: `src/my/task.clj`, `resources/seon/schemas/seon.test.member.edn`, `src/seon/test.clj`,
  `resources/seon/schemas/seon.task.edn` (`my.task`'s request schemas live there), `test/seon/competency_test.clj`.
- `my.task/answer` `[:=> [:cat [:map [:seon.test.run/tested-branch :seon.test.run/tested-branch]]] [:or :map :seon.error/value]]`:
  reads, through A1's `my.agent/answer`, the answer of the agent whose branch is the tested branch (outside a test
  member the input is missing and the call refuses by name), and records the answer's structural digest
  (`seon.id/id` of the pulled answer map) on the member as `:seon.test.member/answer-digest [:string {:min 1}]` (new,
  optional in `:member`). `:seon.test.run/tested-branch` is installed (`seon.test.run.edn:29`, optional on the run at
  `:125`); a member world must supply it for the supplier to fill it: confirm with one `eval_clj` inside a test body
  before writing; if the member world does not carry it, the card returns to root.
- `seon.test/verified?` (`test.clj:1573`, 2-arity): green additionally requires, when the result carries
  `:seon.test.member/answer-digest`, that it equals the digest of the tested branch's current answer.
- Proofs: `seon.competency-test/an-answer-without-code-runs-its-proof`, `…/a-changed-answer-invalidates-green`,
  `…/a-changed-answer-source-invalidates-green` (ledger row).
