# RT-14 Root is woken only by an assignment

Ledger §3.28 RT-14 (group B; the class regression). Lane: Sonnet.

## What becomes true
No producer opens a root model turn except by assigning root a task with a red proof. Root's listened attributes are
messages (`:seon.message/to`), schedule firings (`opens-turn? false` already), settled effects and assignments (RT-1);
with CX-2 a message or an effect opens no turn unless root holds a task, and after RT-9, RT-11, RT-12, RT-13 no
Seon producer sends root a message. Messages from people and agents still reach root and show in its block when it
next works a held task.

## Functions
- A sweep: `rg -n ':my.message/to \"root\"|message/send!|message-tx' src` lists every remaining producer that
  addresses root; each is converted to `ask-tx` or deleted in this commit, or named in the card's landing note with the
  card that deletes it (CX-3 system turns, CX-6b the demo seed, CX-8 root's supervision turn in `seon.bootstrap`).

## Deleted
Whatever the sweep finds that the earlier cards left.

## Proof
`seon.turn-work-test/root-is-woken-only-by-an-assignment` (new, a table): for each producer (a core error, a merge
request, a stopped automatic merge, a give-back, a cap, a schedule firing, a message from an agent) fired against a
root that holds nothing, `next-agent-work` for root is nil exactly for the rows that assign nothing, and `:open` for the
rows that assign root a task.

## Cost
D: the narrow proof; the sweep is one search.

## Dependencies
RT-9, RT-11, RT-12, RT-13, CX-2, CX-3, CX-6, CX-8.
