# CO-11 A contract's scope is honored; an arm that accepts everything is not run

Pattern P2 (merged.md D6; Opus I3/F2, Astra B3). Lane: Opus. Malli fork `418df441`.

## What exists
`seon.instrument/compiled-wrapper` passes `{:scope #{:input :output :guard}}` literally to `m/-instrument`
(`malli.core/-instrument` defaults the same and the function schema's `-instrument-f` reads `:scope`). Arms whose
schema accepts every value (`[:cat :any]`, `:any`, `:seon.schema/value` when it is `:any`) still run a validator.

## Change
Fork: `-instrument-f` drops an arm whose compiled schema accepts every value (identical refusals: it can never
refuse). Seon: `compiled-wrapper` reads `:scope` from the contract's properties, default full; no contract declares
a narrower scope (owner: keep every check).

## Proof
Fork test: an `:any` input arm calls no validator (counted by a validator wrapper in the test). Seon
`seon.instrument-test/a-contract-declares-its-scope` (new) plus the existing
`seon.instrument-test/host-boundaries-enforce-per-arity-declared-schemas-in-both-modes` and
`seon.instrument-test/jvm-and-interpreted-functions-arm-the-declared-guard`.

## Cost
Expected: one validator call fewer per elided arm. Parent: every arm runs.
