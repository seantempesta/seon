## Part 1: `:my.program/context` is a world member

- `seon.batch/world-members` gains `:my.program/context :my.program/context`.
- `seon.turn.world/agent-world` (and so `test-agent-world`, `merge-world`) assocs `:my.program/context` when it has a
  ctx and a base: `{:seon.sci.eval/ctx ctx :my.program/base-ctx base :seon.db/connection conn :seon.cluster/name cluster :seon.env/environment environment}`
  plus `(seon.batch/environment-members environment)`. Use the forked ctx the world already holds (one value, not a
  second fork). `jvm-world` has no base: no member, so a call needing it refuses by name (as `supplied-context`'s
  refusal does today). Add the optional member to `:seon.batch/world` (`resources/seon/schemas/seon.batch.edn:2`).
- Delete `my.program/supplied-context` and its row.
