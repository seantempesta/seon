# S5-05 An eval request delivers the errors it observed

Ledger row S5-05 (group B). agent-loop.md §3.1 deletes "the fault-window query". Lane: Sonnet. Cited at HEAD
`e7f120672`.

## What exists
`seon.turn/fault-window` (`src/seon/turn.clj:3478-3496`) queries every error written on the agent's branch between the
agent's previous settlement and now (`seon.error/occurred-since`, `src/seon/error.clj:1547`) and `with-fault-windows`
(`:3498-3510`) saves those signatures as `:seon.cluster.eval/faults` on the batch's last evaluation. It reads whole-
branch history per settlement and attributes other work's errors to this eval request. PB-07a (ledger) separately
fixes its empty case; this row deletes it.

## Change
- The fold knows what it observed: the batch's diagnostics and `produced-failures` (`src/seon/batch.clj:629-649`) are
  recorded by `record-faults` (`:651-662`) after settle. Move the fault stage before RECORD for the signatures:
  `record-faults` returns each recording's `:seon.error/signature` (the fault receipt answers it:
  `seon.fault/recorded`), and `settle` writes them on the last evaluation as `:seon.cluster.eval/faults`
  (`[:vector [:tuple [:= :seon.error/signature] :seon.error/signature]]`, the shape `fault-window` returns). Order in
  `evaluate-batch` (`:687-761`): derive → fault (recording the diagnostics known so far) → settle (with the observed
  references) → a settle failure's own diagnostic is recorded after, as today.
- DELETE `fault-window`, `with-fault-windows` and their call in `settle-batch!` (`:3615`); `render/transcript.clj:348-360`
  reads `:seon.cluster.eval/faults` unchanged.
- Background effect errors that complete after their eval request reach the agent through their own notification
  (`:seon.effect/notify`), not through a later eval request's window.

## Proof
`seon.cluster.turn-test/a-pass-delivers-only-the-errors-it-observed` (ledger name, new): agent A's eval request
produces a core error (a stub host function throwing a classified `ex-info`); between A's two eval requests another
writer records an unrelated core error on A's branch; A's second eval request's last evaluation has no
`:seon.cluster.eval/faults` and the first's names exactly its own signature.
