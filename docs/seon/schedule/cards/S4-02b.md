# S4-02b The static prefix (absorbs CS-06)

Ledger row S4-02b (group B/H). Spec: agent-loop.md §3.4 table row "Static prefix" (`(help)`'s value, derived per
loaded commit, cached in `seon.cache`, never stored, no opening pass). Over 15 minutes as one row: split into
S4-02b1 (add the prefix) and S4-02b2 (delete the opening). Lane: Sonnet each.

## S4-02b1 The prefix is the system message

### Files
`src/seon/turn.clj`, `src/seon/bootstrap.clj`, `test/seon/cluster/turn_test.clj`.

### Functions
- ADD `seon.bootstrap/static-prefix`
  `{:malli/schema [:=> [:cat :seon.db/database-value :seon.agent/id] :string]}` `[database agent-id]`.
  Body: `(seon.cache/lookup ::static-prefix [(db/commit-id database) namespace-name] #(* 2 (count %)) #(seon.render.value/text {:seon.render/value (help-value database agent-id) …}))`.
  The key holds exactly what `help-value` reads today (`src/seon/bootstrap.clj:17-60`: the loaded program and the
  agent's namespace name); H-01 later makes help literal and drops the namespace from the key. Printing goes through
  the one value printer (`seon.render.value/text`, as `seon.repl/shown-output` does at `src/seon/repl.clj:177-192`).
  `seon.cache/lookup` (`src/seon/cache.clj:160`); `seon.db/commit-id` (`src/seon/db.clj:3334`).
- CHANGE the model call request in `seon.turn` (the `(assoc primary :seon.ai/prompt text)` at `src/seon/turn.clj:4646`):
  also `:seon.ai/system (bootstrap/static-prefix observed-db agent-id)`. `seon.ai/request-body` already sends
  `:seon.ai/system` as the system message (`src/seon/ai.clj:561-576`).

### Proof
`seon.cluster.turn-test/the-static-prefix-is-byte-identical-across-calls-of-one-commit` (new). Two fixture-model
passes of one agent on one commit: the two request bodies the HTTP fixture received have `=` system messages; after a
`defn` committed and loaded (a different commit) it may differ. Assert on the captured request bodies (data).

### Cost
A hit is one cache lookup (~200 ns, `cache.clj` ns doc); a miss prints `(help)` once per commit and namespace,
proportional to the help text. L.
