# CO-12 Name the queries a ping runs

Patterns P4/P1 (diagnosis). Lane: Sonnet. Runs only on the post-rip-context measurement.

## What exists
Pre-rip: a quiet `:ping` makes 48 `seon.db/q` calls (83 MB in `seon.db/vector-query-call`, ~41 ms) and 128-138
reads (feedback-design §1). Which owners issue them is unknown (JFR depth 64 hid it); some may belong to capture or
prompt reads that rip-context deletes.

## Change
Diagnosis: after rip-context lands, measure one `:ping` with `seon.profile/measure` and the call sink's per-definition
self time (feedback-design slice 4 when landed), list each `q`/`pull` caller with count and bytes, and file one
ledger row (P1 or P4) per owner whose reads do not follow the request.

## Proof
The owner table committed under `docs/research/agent-platform/2026-10-08/cost-design/`, each row with its task.

## Cost
Expected for a `:ping`: its recording transaction and the step's lookups, a handful of reads.

## Dependencies
rip-context landed; CO-0.
