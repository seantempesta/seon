# PB-15: `breaks` on a namespace walks its gate set once

Ledger row PB-15 (group E/M; waste row W-19). Task `my.program/breaks-on-a-namespace-subject-takes-five-seconds`
(filed by lane led-nk1, which tagged `my.program-test/schema-and-namespace-reads-keep-different-connections-distinct`
with it). Model: Sonnet.

`my.program/breaks` on a namespace subject (`'seon.turn`) takes 5.5-5.9 s; on a function subject 183 ms. The test above
exceeds its 5 s bound. Expected from the work: the namespace's callers and the tests reaching its functions, found in
one reverse walk.

Cause, from source (verify with the probe below before editing): for a namespace, `breaks` passes every function and
test the namespace owns (`owned-functions`, `my/program.clj:280-282`, about 200 for `seon.turn`) to the positional
`seon.fn/gate-sets` (`fn.clj:2019-2023` → `gate-sets-in`, `:1882-1922`), which reads the whole program's edges once
and then runs `gate-set-in` (`:1857`) **once per seed** (`gate-sets-in`'s final `reduce`, `:1916-1922`). `breaks` then
only takes the union (`(mapcat val gates)`, `my/program.clj:299`). `gate-set-in` already accepts many seeds
(`[database identities tests incoming seeds]`) and its reverse walk is monotone, so the union of per-seed walks equals
one walk seeded with all of them.

## Probe first

`seon.pass-probe/window` (or `seon.profile/explain` on the armed counters) around one `breaks` of `'seon.turn` on a
throwaway cluster: confirm `gate-set-in` calls ≈ owned functions and that they dominate the 5.5 s. If not, stop and
report the measured owner.

## Functions

- ADD (extract) `seon.fn/gate-edges` (private) `[database]` → `[:or [:map [:seon.fn/identities [:map-of :int :qualified-symbol]] [:seon.fn/tests [:set :qualified-symbol]] [:seon.fn/incoming [:map-of :qualified-symbol [:set :qualified-symbol]]]] :seon.db/invalid-read-error]`:
  the body of `gate-sets-in` up to `incoming` (`:1890-1915`), unchanged. `gate-sets-in` calls it.
- ADD `seon.fn/gating-tests` `[database function-symbols]`, contract
  `[:=> [:cat :seon.db/database-value [:sequential :qualified-symbol]] [:or [:vector :seon.test/sym] :seon.db/invalid-read-error]]`,
  docstring "The tests gating any of `function-symbols`: one reverse walk seeded with all of them.": `gate-edges`, then
  one `gate-set-in` with all symbols, answer `(vec (sort (:seon.fn/tests closure)))`.
- CHANGE `my.program/breaks` (`my/program.clj:286-299`): replace `gates`/`:seon.program/gating` with
  `(seon.fn/gating-tests database (vec gate-names))` (refusal handling as today), so a function subject also takes the
  one-walk path.

## Proof

New `seon.fn-test/gating-tests-equals-the-union-of-per-function-gate-sets`: on the test world, for the functions of one
namespace with several callers and tests, `(fn/gating-tests db syms)` equals
`(vec (sort (set (mapcat val (fn/gate-sets db syms)))))`.

The existing `my.program-test/schema-and-namespace-reads-keep-different-connections-distinct` passes inside its 5 s
bound (it names the task).

`--test seon.fn-test my.program-test`

## Cost

Expected: one whole-program edge read (the 183 ms a function subject costs today) plus one walk over what the seeds
reach. The edge read itself is whole-program per call; that remainder is recorded on the task, not fixed here.
Measure `breaks 'seon.turn` on parent and change; report both.

## Deleted
