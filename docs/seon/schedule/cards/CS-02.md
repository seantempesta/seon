# CS-02: The block is one ordinary evaluation

Depends on: CS-01b, CS-01c1, CS-01c4. Group D. Model: Sonnet.

Owner ruling (2026-10-08): no block budget. Every REPL evaluation is its own context unit under the ordinary
per-evaluation display budget (2,000 tokens by default, with the usual override); the block is one such evaluation, and a
task needing more context gets it through more evaluations (`doc`, `source`, `my.fs/section`).
Spec: agent-loop.md §2 "Context tokens", §3.4.

## Files

- `src/seon/context.clj`
- `resources/seon/schemas/seon.context.edn`
- `test/seon/context_test.clj`
- `test/seon/pass_probe.clj`

## Functions

`seon.context/current-state-ai` (CS-01a) becomes the block's whole AI render:
- order the sections Task, Proofs, Broken tests, Must-reads, Unread, Turns by returning them as an
  `array-map` in that order (the printer keeps insertion order of a small map; the render ranks, the printer never
  does);
- when every proof is green, nothing is broken and nothing is unread, collapse Proofs, Broken tests, Unread and
  Turns into one `:seon.context/status` map `{:proofs {:green n} :calls-left k}` (the spec's quiet line); Task and the
  proof sources always show;
- put no budget on it: no metadata, no clipping; the value printer prints it like any evaluation.
Contract: `[:=> [:cat :seon.context/current-state] :seon.context/current-state-view]`; add
`[:seon.context/status {:optional true} [:map [:proofs [:map-of :seon.context/proof-status [:int {:min 1}]]] [:calls-left :my.agent/turns-left]]]`
to the view.

`test/seon/pass_probe.clj`: add one probe row `block` timing `(seon.context/current-state db agent-id)` and its
render, in the probe's existing row shape (read `seon.pass-probe/window` first and copy its form).

## Proofs

`seon.context-test/an-over-budget-block-offers-its-elision-forms`: a task naming 60 must-read symbols; read the block
through `seon.mcp/call`; assert the reply data carries the printer's ordinary elision form on the block's result
symbol (the same cut any over-budget evaluation gets), and the view carries no `:seon.print/budget`.

Render-garbage check (PR-12's shape): assert `current-state-ai`'s value is a map, never a string.

`--test seon.context-test --test seon.print-test`.

## Cost

Proportional to what the block shows; the ordinary per-evaluation display budget bounds the shown text.
