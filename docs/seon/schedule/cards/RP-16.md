# RP-16 A data entrance for models

Ledger row RP-16 (DATA, competency C6; group B/C). Design: `redo/pass-and-recording.md` §3 (the DATA reader, steps
1-6) and owner question 6 (answered by the approval: `:forms` elements are read at the cursor, not pre-read values).
Rulings: "entrances as read stages (model text, MCP code, EDN data `{:ns … :forms […]}` returning envelope maps)";
agent-loop.md §3.2. Lane: Sonnet. Cited at HEAD `e7f120672`.

## Change
- A third read mode `:data`. `seon.sci.forgive/read-state` gains `[text mode]` handling for `:data`: one structural
  scan (the existing `scan` in `:code` mode, `src/seon/sci/forgive.clj:124`) over the reply finds the top-level map,
  its `:ns` and `:forms` keys and the span of each `:forms` element. The read state is
  `{:seon.batch/version {:seon.batch/text text :seon.batch/pos <first element start>} :seon.batch/data-spans [[s e] …] :seon.batch/start-ns <ns symbol>}`.
- `seon.sci.batch/read-next` in `:data` mode reads the next element with `sci/parse-next` from its span **when it is
  due** (the cursor), so `::alias/k`, `*data-readers*` tags and `#?` behave as in code mode; a string element is a
  string literal; an element that fails to read is its own error and reading continues at the next span; no
  forgiveness in `:data`.
- A reply that is not one map, lacks `:forms`, has a non-vector `:forms` or carries keys other than `:ns` and
  `:forms` fails once: one call row, one read error (`:seon.error/type :seon.batch/data-shape-error`, a new variant in
  `seon.batch.edn` extending `:seon.error/base` with `[:seon.batch/text :string]`), no evaluation.
- The eval request's start namespace is the map's `:ns` (read by SCI from its token span).
- The reply is the vector of envelope maps the MCP reply already uses, one per element (`seon.repl` response map).
- The dial `:seon.config.ai/entrance` `[:enum {:seon.config/default :repl} :repl :data]` in
  `resources/seon/schemas/seon.config.ai.edn` (per-agent overlay as the other `:seon.config.ai/*` dials); `call-turn`
  passes `:seon.batch/mode (case entrance :repl :reply :data :data)` into the submission (RP-11b).
- `seon.batch.edn`: `:mode` enum gains `:data`.

## Functions
- CHANGE `seon.sci.forgive/read-state` (`:338`): add arity `[text mode]`
  (`[:function [:=> [:cat :string] :seon.batch/read-state] [:=> [:cat :string :seon.batch/mode] [:or :seon.batch/read-state :seon.error/base]]]`).
- ADD `seon.sci.forgive/data-spans`
  `{:malli/schema [:=> [:cat :string] [:or [:map [:seon.batch/ns-span [:tuple nat-int? nat-int?]] [:seon.batch/data-spans [:vector [:tuple nat-int? nat-int?]]]] :seon.error/base]]}`
  `[text]`: the scan described above.
- CHANGE `seon.sci.forgive/step` (`:320`) / `next-form` (`:371`): `:data` mode reads the span at
  `(first data-spans)` and pops it.

## Proof
`seon.repl-differential-p8-test/data-forms-read-at-the-cursor` (new), the reader called directly through the fold
with `turn.batch/program-request` `:seon.batch/mode :data` (the turn-test fixture `support/code-request` with the mode
overridden), three rows:
1. `"{:ns rp16.a :forms [(require '[clojure.string :as s]) ::s/x (s/upper-case \"a\")]}"`: values
   `[nil :clojure.string/x "A"]` (the alias the first element requires resolves in the later elements);
2. `"[1 2]"`: one read error of type `:seon.batch/data-shape-error`, zero entries;
3. `"{:ns rp16.b :forms [(+ 1 2) #unknown/tag 1 (+ 1 2 3)]}"`: values `[3 <read error> 6]` (the unreadable element
   is its own error; reading continues).
And through the fixture model with the dial set to `:data` on the agent: one model eval request answers envelope maps.

## Cost
One linear scan plus one read per element.
