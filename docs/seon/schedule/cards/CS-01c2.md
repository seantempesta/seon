# CS-01c2: The block shows library names with their pinned revision

Depends on: CS-01c1 (`seon.context/must-read`). Group D. Model: Sonnet.

## Files

- `src/seon/context.clj`
- `resources/seon/schemas/seon.context.edn`
- `test/seon/context_test.clj`

## What is true at HEAD (probed, JVM mode on default)

- `(find-var 'malli.core/validator)` is loaded; `(io/resource (:file (meta v)))` is
  `file:…/data/source/pins/reference-code-malli/43c6dca8d2d8df3162b13725939954807be4a4ed/src/malli/core.cljc`.
  The URL itself carries the project and the pinned revision: the path element after `pins` is
  `reference-code-<project>`, the next is the 40-character revision.
- `datahike.versioning/merge!` resolves the same way (`reference-code-datahike/86c3301a…`).
- `(find-ns 'datahike.norm.norm)` is nil: not loaded, so unresolved (nothing is loaded to answer).

## Functions

```clojure
(defn- pinned-revision
  "The reference-code project and pinned revision a loaded resource URL names, or nil when it is not under a pin."
  {:malli/schema [:=> [:cat :string] [:or :nil :seon.context/pin]]}
  [url] ...)
```

Body: `(java.nio.file.Paths/get (java.net.URI. url))`, iterate its name elements (`(map str (iterator-seq (.iterator path)))`),
find the element after `"pins"`; when it starts with `"reference-code-"` answer
`{:seon.context/project (subs e 15) :seon.context/revision <next element>}`. No regex.

```clojure
(defn- library-name
  "A qualified symbol or namespace resolved read-only from the host's loaded Vars, with its pinned revision."
  {:malli/schema [:=> [:cat :symbol] [:or :seon.context/must-read :seon.context/name-problem]]}
  [name] ...)
```

- `(find-var name)` non-nil → `{:seon.context/name name :arglists (:arglists m) :doc (first doc line)
  :seon.context/pin (pinned-revision (str (io/resource (:file m))))
  :seon.render/operations [(list 'doc name) (list 'clojure.repl/source name)]}` (`m` = `(meta var)`; the first doc
  line by `seon.sci.eval/docstring-parts` `sci/eval.clj:1891`, as CS-01c1).
- Else, for a namespace name (a simple symbol such as `datahike.norm.norm`), `(find-ns name)`: non-nil → `{:seon.context/name name :doc … :seon.context/pin
  (pinned-revision (str (io/resource (str (-> (str name) (str/replace "-" "_") (str/replace "." "/")) ".cljc"))))}`, trying
  `.clj` when `.cljc` is absent; operation `(doc name)`.
- Else `{:seon.context/name name :seon.context/problem :unresolved}`.

Change `must-read` (CS-01c1): where it now answers `:unresolved` for a symbol, call `library-name` instead. The
store is never read or written for library names.

Note for the spec: the `doc`/`source` operations answer for library names only after S1-06 and S1-08; this card
offers them regardless (the ledger row says so).

## Schemas

```clojure
:project [:string {:min 1}]
:revision [:string {:min 40 :max 40}]
:pin [:map [:seon.context/project :seon.context/project] [:seon.context/revision :seon.context/revision]]
```

Add `[:seon.context/pin {:optional true} :seon.context/pin]` to `:seon.context/must-read`; widen
`:seon.context/name` to `[:or :qualified-symbol :simple-symbol :qualified-keyword]` (a namespace name is a simple
symbol when it has no `/`: `datahike.norm.norm` is a simple symbol), and make `referenced-names` (CS-01c1) also keep a
backticked simple symbol containing a `.` (a namespace name).
