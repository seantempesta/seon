# CX-12 Wire formats: the model's own forms as its own messages

Ledger row CX-12 (group D; replaces CS-03a and CS-03b). Spec: agent-loop.md §3.4 "Wire formats" (one pure adapter
`seon.ai/messages [wrapping prefix exchanges block]`; A `:transcript`, B `:chat`). Lane: Sonnet.

## Evidence

In format A the model's own forms arrive inside a user message. The live flash run read them as someone else's: its
last pass addressed itself ("You're out of turns… your last few turns have been you talking to yourself") and
advised instead of acting. Format B puts each form text in an assistant message and its envelope in the next user
message, so the model's history is its own.

## What becomes true

- ADD `seon.ai/messages` `{:malli/schema [:=> [:cat :seon.ai/wrapping :string [:vector :seon.ai/exchange] :string] :seon.ai/messages]}`:
  `:transcript` = system prefix, one user message of exchanges then the block; `:chat` = system prefix, per exchange an
  assistant message (the forms as sent, with their comments) and a user message (the envelopes, and CX-11's step), the
  block as a second content part of the last user message (or the only user message before the first exchange).
  Pure: strings in, messages out.
- `:seon.ai/exchange` = `{:seon.ai/sent string :seon.ai/reply string}`; `model-context` (CX-1) answers exchanges in
  that shape.
- CHANGE `seon.ai/request-body`: `"messages"` = `(messages wrapping system exchanges prompt)`.
- ADD the dial `:seon.config.ai/wrapping` (`[:enum :transcript :chat]`) on the model row with an agent overlay;
  default per Q-CX2.

## Proof

`seon.ai-test/each-wrapping-builds-its-wire-messages` (pure table): empty history, one and three exchanges, both
formats; the last content is the block; adding an exchange leaves every earlier message byte-identical.
`seon.cluster.turn-test/a-chat-model-request-carries-its-forms-as-assistant-messages` (fixture model).

## Cost

L: proportional to the text (one pass building the vector).

## Dependencies and order

CX-1 (and CX-11 if landed first, to place the step in the user message). Files: `src/seon/ai.clj`,
`resources/seon/schemas/seon.ai.edn`, `resources/seon/schemas/seon.config.ai.edn`, `config/default.edn`,
`src/seon/context.clj`, `src/seon/turn.clj`, `test/seon/ai_test.clj`. CS-03c (prefix continuation) follows it.
