# S4-02a A call row names its assignment

Ledger row S4-02a (group B). Spec: agent-loop.md §3.4 "History" (the assignment boundary; a model exchange is a call
row with a model attempt). Lane: Sonnet. **Q1 answered (owner 2026-10-08 late):** the call row stores its assignment key as a value read once per pass
(option 1, implemented below).

## What already holds
A model pass's call row already owns its attempts: `:seon.turn/attempts` is a component of `:seon.turn/turn`
(`resources/seon/schemas/seon.turn.edn:12,137-140`, written at `src/seon/turn.clj:4273`). Nothing is added for the
attempt; S4-03 reads it.

## Schema
`:seon.turn/assignment :seon.task/assignment` in `seon.turn.edn` and
`[:seon.turn/assignment {:optional true} :seon.turn/assignment]` in `:seon.turn/turn`. It is a VALUE (the 12-char
assignment key), not a ref: the assignment is written at the task home (`seon.task.edn:68`), which an agent branch
forked earlier does not hold. Aliasing strips identity (`src/seon/schema/datahike.clj:101-107`).

## Functions
- ADD `seon.turn.world/assignment-key`
  `{:malli/schema [:=> [:cat :seon.db/connection :seon.agent/id :seon.task/branch] [:or :nil :seon.task/assignment]]}`
  `[connection agent-id branch]`: `(:seon.task/key (seon.task/assignment (db/db (seon.task/home-connection connection)) agent-id branch))`
  when that answer is not an error value, else nil (no assignment is ordinary for outside agents).
  Seams: `seon.task/assignment` (`src/seon/task.clj:510`), `seon.task/home-connection` (`:391`).
- CHANGE `seon.turn.world/agent-world` (`src/seon/turn/world.clj:40`) and `jvm-world` (`:76`): assoc
  `:seon.task/assignment` when `assignment-key` answers one. Declare it optional in `:seon.batch/world`
  (`resources/seon/schemas/seon.batch.edn:232`).
- CHANGE the model pass's inline world (`src/seon/turn.clj:4977-4986`) the same way.
- CHANGE `seon.turn.batch/record-facts` (`src/seon/turn/batch.clj:676`): add `:seon.turn/assignment` from the world
  to the record-call map when present. Contract unchanged.
- CHANGE `seon.turn/open-call` (`src/seon/turn.clj:374`): optional `[::assignment {:optional true} ::assignment]` in
  its request schema, copied onto the row.

## Proof
`seon.cluster.turn-test/a-pass-call-row-names-its-assignment-and-attempt` (new). Setup: assign a task to an agent
(the harness's canonical task writer), one fixture-model pass and one `seon.mcp/call` SCI pass. Assert:
`(:seon.turn/assignment row)` equals the assignment key for both; the model pass row has a non-empty
`:seon.turn/attempts`, the MCP row none; an unassigned agent's row has no `:seon.turn/assignment` key.
