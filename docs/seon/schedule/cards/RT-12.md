# RT-12 A new error signature asks its steward or root

Ledger §3.28 RT-12 (group F; amends errors.md §6 "Opening"). Q-RT2 (recommended option assumed). Lane: Sonnet.

## What becomes true
- When a recorded error's signature OPENS (absent or resolved, errors.md §6), the same home transaction asks (RT-7)
  the function's steward if one is held, else root, about the error row (`:seon.task/about #{error}`), in the producer's
  namespace (the error's operation's namespace). A repeat only counts (TX-3a) and asks nothing.
- The error row refs its question (`:seon.error/task`, the "task" of CLAUDE.md's "with a count, a task and one
  notification"; the assignment is the one notification). Resolution is unchanged: it follows the tasks the decision
  filed (their proofs green on the home after `latest-at`) or the producer's deletion; the question itself is no
  proof of a fix.
- Over-bound health findings that Seon records as its own errors take the same route; nothing else is added for them.

## Functions
- CHANGE the recorder's writer function (`seon.error/commit-call` today; the row writer after E-P4): replace
  `message-tx` over `recipients` with `seon.task/ask-tx` for the one recipient the existing steward/escalation choice
  picks (steward else root); the agent the error happened to is still never the recipient.
- CHANGE `seon.error.edn`: `:task` optional ref on the error row; delete `:notified`.

## Deleted
`message-tx` for errors, `:seon.error/notified`, the `:seon.config.error/escalate-to` dial and its schema member (root
is the task home's root), the printed-map message content. Retires task
`seon.error/error-notifications-to-root-are-printed-maps` (delete its entry in `resources/seon/tasks/seon.error.edn` in
this commit).

## Proof
`seon.fault-test/a-new-error-signature-asks-root-once` (new; through `seon.mcp/call` as an agent with no steward for
the failing function): one core error ⇒ root holds one question about the error row and has no new message; the same
error again ⇒ the count is 2 and root still holds one question; `seon.fault-test/a-steward-is-asked-instead-of-root`.

## Cost
New signature: TX-3b's one home commit, now carrying the question (≈ 13 datoms) instead of a message (≈ 6); repeat:
0 commits, as TX-3a.

## Dependencies
TX-3b, RT-7. Lands before E-SDELETE folds the recorder into `seon.error` (whichever lands second keeps the rule).
