# RP-14 One commit per model eval request (after the message)

Ledger row RP-14 (S6-04a, group B; corrected by the census fold-in, `redo/pass-and-recording.md` §2.1). Both censuses:
a model eval request is 7 commits including the incoming message, 548-779 ms, 496-593 KB on the throwaway
(`tx-census-astra.md` model table; Opus: wake, system turn, open, capture, attempt, plan, record). After RP-10 (plan),
S4-02b (system turn), S4-07b3 (capture) and this row (open, attempt), it is the message plus ONE recording.
**Correction applied:** the open and the attempt's timestamp are not carried into the recording; the call row is
written once, by the recording, and the transaction is its open and its instant. Lane: Sonnet. Cited at HEAD
`e7f120672`. Three lettered slices.

## RP-14a: the run opens in its recording

### What exists
`seon.turn/open-turn` (`src/seon/turn.clj:4353`) commits `[:db.fn/call #'open-call open-request]` before the provider
call; its transaction t is the answered basis ("ANSWEREDNESS IS THIS TRANSACTION'S OWN `:t`", `:4374`). The agent's
Flow proc runs one turn at a time, so the writer-side busy fence (`open-call`'s no-op on a second opener) guards
nothing a second proc could do.

### Change
- `open-turn` commits nothing: it mints the run id with `(id/id)` (as `submit-source-in-projection` does,
  `src/seon/cluster/agent.clj:759`; `next-id` `:499` is deleted if no other caller), and answers the report with the
  open request in the work (`:seon.turn/open-request`).
- `call-turn` (`:4430`) builds ONE submission at its start:
  `{:seon.db/tx-data [[:db.fn/call #'open-call open-request]] :seon.turn/open-request open-request}`, and every
  settlement path passes `(assoc cluster :seon.turn.loop/submission submission)`: `freeze!` (RP-10's submission
  merges its reply facts into this one) and `fail!` (`settle!` already prepends the submission through
  `with-submission`, `:3512`, `:3984`). So a provider failure records the call row with its error in one commit too.
- The answered basis is the recording's `:seon.db.transaction/basis-t` (TX-0: the world's basis is the context's
  presented basis); S6-05 reads it. Until S6-05 lands, readers of "answered = the open's t" read the call row's
  transaction t instead (`rg -n 'opened-tx' src/seon/turn.clj` lists them; `latest-answering-turn-t` `:2908` is one):
  the recording's t is later than the old open's t, so a wake arriving during the provider call would be answered
  too early. **Therefore RP-14a lands only together with or after S6-05** (ledger dependency added).
- `:seon.turn/opened-tx` is no longer written by the model path (the recording's `record-evaluated-call` writes
  `::opened-tx "datomic.tx"`, `:1374`: delete that assoc with TX-8b, which converts its readers).

### Proof
`seon.cluster.turn-test/a-model-reply-pass-commits-its-evaluations-once` (RP-10's test) gains: the transactions on the
agent's branch carrying the eval request's id (TX-0's `:seon.db.transaction/eval-request`) number exactly 1 after a
model eval request whose forms write nothing; `seon.cluster.turn-test/a-provider-failure-records-its-call-row-once`
(new): a fixture provider answering 500 → one transaction carrying the eval request id, holding the call row and its
error.

### Files / commit
`src/seon/turn.clj`, `test/seon/cluster/turn_test.clj`.
`bin/lane commit <lane> -m "RP-14a: a model eval request opens in its own recording" --test seon.cluster.turn-test --test seon.turn-test --test seon.turn-work-test --test seon.turn-loop-test src/seon/turn.clj test/seon/cluster/turn_test.clj`

## RP-14b: the attempt rides the recording

### Change
`record-attempt!` (`:4134`) commits the attempt row (and its error fact) on its own. Its row joins the recording as
EN-2's `:seon.turn.batch/call-facts` (the attempt row map with `:seon.ai.attempt/*` measured data: model, endpoint,
usage, latency, finish; **without** `:seon.ai.attempt/at`, which the transaction's `:db/txInstant` answers). The
`attempt-request`/`attempt-evidence` builders (`:4089`, `:4052`) stay; `record-attempt!` becomes
`seon.turn/attempt-facts [request now] → [:vector map]` (pure; contract
`[:=> [:cat :map :inst] [:vector :map]]`), and `call-turn` puts them in the submission's call facts. A provider
failure's error fact rides the same recording. Readers of `:seon.ai.attempt/at` (`rg -n 'seon.ai.attempt/at' src`:
`turn.clj`, `cluster/status.clj`, `cluster/prompt.clj`, `render/transcript.clj`, `eval/drive.clj`) read the attempt
entity's transaction instant instead (`[?a :seon.ai.attempt/id _ ?tx] [?tx :db/txInstant ?at]`); the attribute is
retired in the schema (`seon.ai.attempt.edn`: keep the key declared as retired until adoption removes it, the
pattern of `:seon.cluster.eval/triage-edn`).

### Proof
`seon.cluster.turn-test/the-attempt-row-rides-the-recording` (new): after one fixture model eval request, the attempt
entity and the call row share one transaction (`(= tx-of-attempt tx-of-call-row)`), and the attempt has no
`:seon.ai.attempt/at`.

### Commit
`bin/lane commit <lane> -m "RP-14b: the model attempt rides the recording; its instant is the transaction's" --test seon.cluster.turn-test --test seon.cluster.prompt-test --test seon.cluster.status-test src/seon/turn.clj src/seon/cluster/status.clj src/seon/cluster/prompt.clj src/seon/render/transcript.clj src/seon/eval/drive.clj resources/seon/schemas/seon.ai.attempt.edn test/seon/cluster/turn_test.clj`
(If S4-07b2/b3 already deleted `cluster/prompt.clj`'s reader, drop that file.)

## RP-14c: delete the open and receipt carriers

### Delete
`seon.db/*open*` (`src/seon/db.clj:183`), `seon.db/*receipt*` (`:179`), their bindings in `call-with-custody`
(`:456-457`) and `seon.sci.eval` (`src/seon/sci/eval.clj:4244-4245`), the stamp's `::receipt` and the `*open*` prefix
(`stamp-transaction` `:3661-3662`), `:seon.db/pending-open` (`turn.clj:4976` and its schema member),
`seon.turn/submission-open-tx` (`:759`) once no submission uses it (the MCP step builds the open with `open-call`
directly), `:seon.db/receipt` from `seon.db.edn` (retired key), and `read-only-evaluation?`'s receipt query
(`turn.clj:1897`) if S4-06 has not already deleted it with the refresh. The tests that asserted the receipt were
converted by TX-0.

### Proof
`seon.db-test/a-transaction-stamp-carries-no-ref-to-an-unrecorded-evaluation` (ledger's name): an agent's
`(seon.db/transact! [])` inside an SCI eval request commits a transaction with `:seon.db.transaction/eval-request` and
no `:seon.db/receipt`, and the agent branch holds no evaluation row before the recording (pull by the handle's id in
the same form answers nil).

### Commit
`bin/lane commit <lane> -m "RP-14c: the open and receipt carriers are deleted" --test seon.db-test --test seon.turn-test --test seon.cluster.evaluate-source-test src/seon/db.clj src/seon/sci/eval.clj src/seon/turn.clj resources/seon/schemas/seon.db.edn test/seon/db_test.clj`
