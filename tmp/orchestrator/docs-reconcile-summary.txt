Docs reconciliation — architecture targets after the claim-native cutover
Date: 2026-07-23

OUTCOME
-------

Reconciled the always-current architecture target with rulings R26-R28 and the
accepted U1-U6a boundaries. The architecture now describes claim-native runs,
the five-role process topology, receipt-based recovery, guarded SCI execution,
required-database-value rendering, the portable capability seam, and loud
configuration-backed circuit breakers.

No source, test, config, operator, roadmap, issue, or conversion-wiki file was
changed. No new conversion trap was found. No issue was filed because the
source/target differences below are already owned by the active program plan
and are not newly discovered defects.

SOURCE/TARGET MISMATCHES FOUND
------------------------------

These are reported, not resolved:

1. The target places render, LLM, eval, and publish in claimant JVMs. Committed
   source still splits the one portable driver across
   src/seon/agent/driver/pod.cljs (render/LLM/publish) and
   src/seon/agent/driver/host.clj (eval only). This is the planned U6b/U7/U9
   cutover boundary, not documentation authority.

2. The target web-render JVM owns the complete route/page/feed system.
   Committed src/seon/web/server.clj currently hand-wires only /data,
   /data/feed, and static assets; the remaining route/render port is the
   planned later web-render slice.

3. The target says every required protective limit is a database config fact
   with no numeric runtime fallback. Committed source still contains protective
   literals outside the reconciled R27 sections, including LLM retry bounds in
   src/seon/agent/turn/core.cljc, shell/web defaults in portable capability
   sources, and invocation deadline/result caps in
   src/seon/agent/driver/host.clj. The docs follow R27; the source sweep remains
   program work.

4. Claim and turn schemas remain registered in src/seon/agent/run.cljs and
   src/seon/agent/turn.cljs while their policy/transaction builders are in
   portable .cljc cores. The target names portable family ownership; schema
   owner promotion/deletion is still part of the cutover.

5. The target writer performs transactions and committed-feed publication
   only, with claimant/web-render reads over process-local replicas. Current
   src/seon/db/host.clj still exposes remote read/session behavior used by the
   landed claimant and first web-render slice. The plan/ruling is the target.

6. The guarded door target covers every SCI invocation class. Committed U1
   integration covers the JVM SCI host; the existing Bun self-host path is
   deliberately temporary and does not use SCI. This closes when the Bun agent
   runtime is deleted rather than by adding a compatibility guard.
