Implemented contracts
---------------------

- Shadow flush hooks select exact `:build-sources`, reuse
  `seon.client.indexing/analyzer-fn-inventory`, and publish sidecars for the
  default, ACME, bench, execution, and release builds.
- Client and execution inventory digests enter the artifact manifest and
  application digest. Tests prove changing an export changes both inventory
  and application identity.
- `seon.capability/installed-artifact-inventory` is the JVM artifact authority:
  it projects the one wrapper/host-binding registry enumerator and preserves
  its digest. A separate JVM analyzer is allowed only after a reachable
  compiled terminal is proven absent.
- Host launch carries the Bun inventory, merges it with the claimant-local JVM
  inventory, and supplies both to `acquire-planning-projection`.
- The P2 compiled-only fixture changes from steering to exact constrained
  placement with real inventories on both JVM and Bun tiers.
- First-party private functions carry source and `:seon.fn/private? true` but
  no callable contract. Public rows omit the privacy attribute. Default
  namespace/menu projections omit private rows; full namespace source drill
  reaches them. The source boundary is repository `src/` plus
  `SEON_EXTRA_SRC`, so vendored `reference-code/` is structurally third-party.
