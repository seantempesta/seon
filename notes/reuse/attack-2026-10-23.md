# Attack on the reuse design (notes/reuse/design.md at 159691f1), 2026-10-23

An independent, read-only review. Verdict: unsound as written; sound for the walk's renders with fixes.

Wrong or stale hits, most severe first:
1. The render that runs is picked from data (`render-of` resolves a symbol from the value or its schema: jolt/walk src/seon/render.clj:129-138, nested at :84-95), and the reach graph doesn't follow it (program.clj:685-688; fx.clj:96-104). Editing `seon.render.ai/task` leaves the key unchanged, and the old text comes back.
2. The key is read from disk or the db, while the value is computed by the running process. `:env` comes from git ls-tree of the working tree (fx.clj:158-178), not from the binary. Schema rows move, but renders read the baked `contract/forms` (contract.clj:89). Load errors carry on (program.clj:719-731). `held?` trusts the source text (:644-654). Removing an `:impl` does nothing (:772-780). So a wrong value is stored under a key that later processes trust.
3. REPL redefinitions: root's REPL records nothing (repl.clj:237), and defmethod and extend change dispatch tables, not var roots.
4. Digests are 64 bits (seon.error/digest, error.clj:32-37), not SHA-256. A content-eid collision throws inside the transaction (datahike transaction.cljc:63-69, 862-868).
5. The canonical argument print is not injective: separators aren't escaped, a record digests like a map, metadata is dropped (renders read it, render.clj:76,127,183), and seq order is collapsed while the printer's handles depend on it (emit.clj:36). Lazy seqs can hang or throw. Unknown objects fall to pr-str (Entity, DB, closures).
6. Results stored as EDN don't round-trip: the :html face holds function objects (render.clj:95).
7. `:pure?` has false negatives: instance calls, constructors, dynamic-var reads, rand, gensym, resolution, println (program.clj:166-175).
8. Tests become dependent on what the store holds.
Eviction by use count: every hit becomes a write (a key that needs updating), counts conflict across branches, and noHistory doesn't bound disk.
Ways the key moves when nothing relevant did: any bin/, web/ or untracked file changes it (fx.clj:131-143); graph-index puts a name in the digest (program.clj:1054).
Fixes it proposed: key the selected render; build the key from what the process runs; record every definition; full SHA-256; gate args to EDN with meta and order, and refuse the rest; store only EDN (the :ai text); no use counts; a full :pure? list; memo off in tests by config.
