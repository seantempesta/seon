## Checked and fine
- Concurrent appends to OUT/failed and OUT/green are one `print` each (O_APPEND, short): no tearing.
- FIFO pool: tokens are consumed before the background subshell starts and returned after it, so no deadlock unless a subshell is killed. `read -u 3` blocks, no poll.
- `wait ${CP[$((i+1))]}` indexes zsh's 1-based arrays correctly. `time ( ... )` in a brace group keeps the exit status.
- `scrambled` (cost_test): the hash is injective for n up to 10000 (k < p), so the ordering is deterministic and a permutation.
- `seed`: 15 hex digits fit a positive long; `pr-str` of parts is stable.
- `fork_server/reap` now removes reaped pids from `:children`, and `:fork` adds the pid before reaping, so `kill` only reaches unreaped children (no pid-reuse hit).
- `shards`: nested ms files work (`fx/write-file` makes parents); `:ms` is a long (`quot`), so `parse-long` holds.
