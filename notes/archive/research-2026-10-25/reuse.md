## Things to decide before building
1. Branch-registered render symbols live in the agent process; root's render proc cannot call them (9). Owner ruling needed.
2. History bound: the design sends the whole conversation; today `kept-turns` + history-budget drops old turns. With handles (`result/eN`) an old result can be a one-liner; define that cap (config key) once.
3. Per-call vs per-form handle (2): multi-form calls break one-call-one-eval; the tool contract should be one form (or one `(do ...)`), else keep per-form handles but name them eN.M.
4. A UI toggle as a recorded :ui eval writes to the agent branch: confirm acceptable branch noise (and merge: evals are observations "never carried by a merge", seon.facts.edn:107).
5. View state granularity: per view id (page) not per tab; and how the agent (separate process) receives it: via the recorded :ui evals (recommended) not via a new channel.
